# 澪衣身与手臂比例修正（2026-10-22，v27）

用户指出 v26 的身体和手臂宽度不协调。v26 只收窄了袖筒中段，却保留了完整宽度的肘部衣料；衣身同时收进较多，肘部显得更鼓。本轮同步调整衣身与上下两片袖料，保留裸露手臂粗细。

## 源模型修改

- 开衫每侧最大内收量由 4 改为 2.5 个作者坐标像素。代表行的源网格横向跨度从 v26 的 202 恢复至 205，原始跨度为 210；中央衬衫、领口和肩根保留。
- 袖筒与上下肘部衣料统一横向收窄最多 8%。两个肘部截面从 40 同步变为 36.8，减少袖筒中段细、肘部鼓出的落差。靠近肩根和袖口平滑回到原尺寸。
- 修改只进入 `torso`、`arm_left/right`、`lower_sleeve_left/right` 五个源网格关键形；裸露前臂、手掌、骨段长度和肩肘腕锚点保留。头部 v24 和裙摆 v25 继续使用。
- 可编辑 CMO3 与正式 MOC3 同步，由已安装的 Cubism Editor 5.3.04 官方导出至 Cubism 4.0 / MOC version 3，仍为 39 参数、58 ArtMesh。原 PSD 和贴图不变；运行文件对比 v26 只有 MOC3 改变。
