# 车辆细节与深色木材（2026-10-24）

公交与货车补充连续转角、灯具内层、轮毂、车门五金及货斗压筋、铰链和插销；保留车漆、橡胶、玻璃与金属的不同响应。广场七类木材由浅蜂蜜色改为深栗棕色。2813 项独占完整回归、24 组原生前后对照及解压应用 211 项完整演示通过；唯一 macOS ZIP 已替换，默认 104 份存档与照片摘要不变。

这是对实际原生截图的内部检查，画面是否符合用户偏好仍由用户试玩判断。Web 没有发布。

## 两种车辆

公交保留原来的车顶、大轮廓、四轮轴心、两扇活动门、13 片车窗和客舱。原下车皮与轮胎存在破碎边界，已按原轮廓重建连续有厚度的表面，修掉窗下腰线褶皱；轮拱内增加暗色内翼子板，避免从轮胎上方看到另一侧路面。前格栅有独立格条、框架与内凹背板，保险杠有圆角和牵引孔；灯具包含单层薄透镜、反光碗、灯芯、密封圈和分色尾灯。轮毂增加凹盘、通风孔、卷边和螺帽，车门合页、把手底座、锁扣随门运动。

货车保留车身主曲面与原有运菜货物，货斗增加压筋、卷边、分段铰链和带固定销的扣件；轮毂有凹面、开孔、螺帽、垫圈及气门嘴，轮胎增加浅槽。前灯使用一层薄透镜，内部反光碗与灯芯可区分。

两种车辆分别在源 GLB、可编辑 Blender 工程和游戏 GLB 中同步。`preserve_source_materials` 仅对 B01/D07 开启；通用导出与运行时不能再把这些指定金属全部压成同一哑光。`VehicleFinish` 保留源颜色、贴图、粗糙度和金属度，使用动漫漫反射/高光；重复车辆共享材质，不增加逐帧处理。车窗反光随视角变化，移除固定 UV 白条，没有新增自发光或实时灯。全局审计仍拒绝继承的法线/ORM 图和未登记的金属响应。

## 深色木材

`PlazaTimber` 使用 `80563b / 7a5138 / 70482f / 68422b` 深栗棕色，覆盖原广场范围内的 A12_bench、P01、P03、P05、P09、P10、MS14_event_board，包括玩家放置路径。原贴图、UV、几何和非木部件保持不变。45 个真实木面采样的资产线性亮度约 0.091–0.110。

日间、雨天和傍晚的桌椅、藤架与木台保持同一棕色系。夜间能读到板缝和支架轮廓，细木纹较弱；没有再压暗主色。鱼池框等不属于这七类的木件保持原颜色。

## 实机性能复测

同机 Apple M5 Max，现有 screen 0，Forward+，4× MSAA，实际 2560×1440 像素。修改前/后按 ABBA 顺序各运行两次，每个视角预热 180 帧后采样 600 个真实渲染帧，保留居民和衣物更新。表中耗时是两次运行中位值的平均；FPS 由该耗时换算。

## 验证和复现

- 公交源/游戏各 41 项，货车源/游戏各 18 项；两车真实支撑面倾角 0°。完整 293 模型审计的材质、连续表面、尺寸和纹理密度检查通过。
- 材质合同 14 项，包括每辆车六种故障注入。最初旧公交被源检查检出 19 项问题；新增轮罩射线另以缺轮罩版本验证。货车新增八种细节检查在旧版均失败。运行时车辆材质旧版失败 5 项，浅木版失败 2 项；当前全量 2813 项通过。
- 24 组同机位修改前/后 PNG、公交车门开启和车辆/木材的白天、雨天、夜间画面。单次完整截图记录连续渲染帧，无脚本或着色器错误；另有 12 张解压应用复拍。
- 桌面 ZIP 通过完整性、签名、包内资源检查及 211 项完整演示，退出 0 后原子替换 `builds/HareMachi.zip`。临时源码副本和解压应用已删除；测试始终静音并隔离存档。

完整演示退出时报告一个 RendererRD Shader RID 未释放，与上一版已验证包的退出诊断逐字相同；没有脚本或着色器编译错误。原始对照在 `evidence/vehicle_finish_20261024/log_classification.json`。
