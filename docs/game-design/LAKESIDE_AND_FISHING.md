# 晴川、镜波湖与钓鱼 · 2026-10-03

## 可以怎么玩

从主街东端进入河边农园，沿菜地前的路向东走，在指路牌旁领取町内会借出的钓竿和 10 份鱼饵。继续沿河可以到柳影河湾，再绕到镜波湖。湖边有草坡、树荫、芦苇、长椅与一座小栈桥，保留大块开阔水面，没有用密集建筑填满新增区域。

四个钓点是晴川浅滩、柳影河湾、镜波湖栈桥和芦苇东岸。到标记附近按 E：

1. 按 E / 空格或界面的按钮抛竿。
2. 浮漂下沉、出现“咬钩了”时再点一次 E / 空格。
3. 按住收线，张力偏高或变红时松开，再继续收。鼠标左键也可操作。
4. 钓起的鱼直接进入背包；Esc 收竿。每次实际抛竿消耗一份鱼饵和 12 分钟，失手或中途收竿不返还；未抛竿离开不消耗。

鱼饵在商店、田中的种子铺和湖畔补给处出售，每份 3 生活币。鲜鱼可在晴町商店和湖畔补给处出售。六种鱼都有对应料理，回家在厨房按原有料理流程制作，也可出售成品。

太晚时不能再开新的一竿。出售沿用已有的每日收购递减规则。背包“鲜鱼”页签方便查看鱼获；K 图鉴新增鱼类页，记录钓获数量、最长尺寸、水域和时间提示。

## 地图范围与小地图

农园与湖区使用连续可走地形，没有在河湾与湖泊之间切换场景。城镇和农园仍沿用原来的区域切换。旧农园边界为 x=-30…28、z=-16…31；新边界为 x=-30…142、z=-34…62。原镇区保持原坐标。

按城镇加农园的区域边界合计，面积约为原来的 2.69 倍；按 1 米采样剔除水面及 1.3 米近岸保护带后，区域地表面积约为 2.40 倍。建筑占地没有另行扣除，远景背景不计入扩展面积。这不是把背景图片放大后称作地图扩容。统计见 `evidence/lakeside_20261003/map-area.json`。

左下角小地图跟随玩家，标出水岸、道路、钓点、补给处、委托目标与返镇方向。按 M 展开区域地图，在晴町和农园 / 湖区两页之间切换；M 或 Esc 关闭。进入室内或其他交互面板时，小地图收起。

地形、湖岸轮廓、路径、钓点和地图投影来自 `LakesideLayout`。湖底确实低于水面，近岸设置仅阻挡玩家的碰撞，镜头不会撞上透明墙。旧木桥保持可走，新栈桥用已有桥梁素材搭建，实际的隐藏 deck 网格承担脚下碰撞，钓点标记按射线测量落在桥面上。

## 钓鱼状态与存档

`FishingSession` 负责抛竿、等待、咬钩、收线、成功和失手。普通游玩、专项测试和画面演示使用同一个状态机。`GameState.begin_fishing()` 先检查水域、时段、鱼饵与背包空间，再扣除资源并创建一次性钓获票据；`land_fish()` 消费票据后才放入背包，重复完成不会重复奖励。背包途中装满会放生，不会把鱼塞出容量限制。

数据在 `game/data/fish.json`，卖价和图标在 items，料理在 recipes，补给处在 shops。钓竿、鱼饵和鱼获沿用原背包；次数、数量和长度记录保存为 v4 SQLite 快照里的可选 `fishing` 字段。旧 v4 存档缺少这个字段时初始化为空，不更改玩家存档目录。未完成的收线状态不跨存档恢复。

## 房屋质感修正

用户指出上一版房屋太干净、重复、像简单程序模型。本轮重点修正 H02 公寓和 S01 商店的近景材质，主体仍是已有 Hyper3D 模型。通过内置 imagegen 编辑精确正交图，加入旧木板的色差、钉头、门把手磨损、补漆、墙面修补、瓦缝和雨篷缝线，然后按原正交相机尺寸投影回原网格。六个公寓门面采用棕、蓝、绿三种门色，窗内竹帘、布帘、书和小盆栽各有区别。

不是把一层随机噪点覆盖到整个房屋。门窗位置、窗洞、五金和原 UV 仍有分工，侧面与背面保留原贴图。新增材质只投到朝向正确的面，独立窗帘使用同一投影，避免上一轮按颜色分面出现碎边。其他建筑本轮未全面重做，整栋贴图密度不足的检查继续保留失败。

## 验证与经验

源工程全量 449 项中 448 项通过，唯一失败仍为上一轮的整栋建筑贴图密度。新增湖区与钓鱼专项 39 项全部通过，包括不同鱼池、时段和天气、扣饵、重复提交、取消、背包满、出售、六道料理、旧存档兼容、实际 SQLite 存读档、湖岸碰撞、环湖路线、实际走上栈桥、小地图坐标与面板退出。

真实输入演示已经从农园走到湖边，经 E / 空格键完成两次钓鱼，再出售、购买调料、回厨房制作和保存。它也发现了单靠“modal 已打开”检查不了的布局问题：全屏钓鱼控件只设 anchors 时仍为零尺寸，卡片跑到屏幕外。新增回归先在旧代码测出 (0,0) 大小并失败；改为 `set_anchors_and_offsets_preset()` 后，画面和测试均通过。布局接口参考 [Godot 4.7 Control 文档](https://docs.godotengine.org/en/4.7/classes/class_control.html)。

地形第一次三角形绕序朝下，实际截图显示地面缺失；已按项目 `WorldBuilder._tri()` 的顺时针约定修正，并用地面射线和真实行走验证。地形网格接口参考 [Godot 4.7 SurfaceTool 文档](https://docs.godotengine.org/en/4.7/classes/class_surfacetool.html)。背景只保留较远的山脊和树层，避免扩图后走近旧背景卡片形成一堵巨大的树林墙。

截图、演示与最终原生包验证记录在 `evidence/lakeside_20261003/`；房屋导出测量在 `evidence/lived_facades_20261003/`。打包结果以该目录的最终验证 JSON 为准。
