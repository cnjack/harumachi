# 家具的使用痕迹与光泽（2026-10-14）

## 原因与处理

柜台、桌椅、长椅和烤箱原来普遍没有材质反光。导出与室内通用处理会去掉高光，部分木家具又被替换为同一套干净木纹。此次保留模型、UV和原图，以独立表面着色补充用途差异。

- 商店柜台、咖啡桌椅、阅读椅与社区桌保留暖桌面和深色框腿。桌前沿、扶手与座面有局部磨亮，未接触的腿与横撑更哑。
- 工具屋、社区工作台与花坊工作面有短浅划痕和少量前角磨耗；居家与书写桌保持较干净的表面。居民室内的程序桌凳同样覆盖。
- 小镇、农园与湖边九张长椅保留原有板色差、木纹和纹理，坐面有轻微磨耗。
- 烤箱区分搪瓷宽柔光、金属控制部件与透光玻璃。浅热色留在炉门密封边外，旋钮旁只有局部手触痕；门封、耐热把手、石板和炉腔保持原材质。
- 咖啡机、冷藏柜与冰柜按钢材、铜把手、涂装和玻璃分别处理。冰柜商品画面保持不透明，蛋糕与牛奶等商品仍可看清。

旧家具的混合图集只在木色与合适几何区域叠加磨耗；餐具、纸便笺、布垫和玻璃不整体换成木材。没有新增模型或调用付费生成。

## 实现与复用

`FurnitureWoodFinish` 在 `WorldBuilder.spawn()` 的基础材质处理之后应用，程序桌凳由 `PublicPlaceArt.bench()` 按单块顶板、腿与下撑应用。连通板件边界只在构建时计算并缓存，运行时不重扫家具三角面。矩阵上传使用 `Projection`，旋转摆放时磨痕随实际部件移动。

`ApplianceFinish` 只处理登记模型的独立表面。自定义光照累积灯光，底色由引擎统一相乘，避免二次染色。独立着色器在后续 `HouseBuilder.toonify()` 中保留。画风规范已改为按材料保留克制光泽。

## 验收入口

- `--only=furniture-finish`：木材21项、家电12项与原炉件/矩阵回归；旧版本的33项新检查正常产生29项失败，没有解析失败。
- `--furniture-finish-review --furniture-review-out=<目录>`：真实场景中的固定机位、家中旧图集、日夜、户外雨天及正常游玩镜头；五个对象另留光泽/磨耗关闭对照，便于核实效果确实进入渲染。
- 每次运行都使用独立 `HARUMACHI_SAVE_DIR`。同机位基线从原提交 `499ef44` 的独立副本生成。

44项专项、2203项独占全量及解压应用205项完整夏季演示全部通过，退出码0；46张解压包原生截图及36组同机位新旧对照完成复核。默认104份存档与照片摘要不变，唯一桌面ZIP已原子更新，临时工程与解压目录已删除。

咖啡桌椅继承既存的游戏木纹层，源GLB有图片时也不再把这层细纹丢掉。真实圆桌、椅座与55×55×510毫米扶手按板件长宽识别；椅背和深色底座不加接触光。高粗糙度的弱环境反射使直接光照阴影中的桌面仍有材料差异。

验收记录：`evidence/furniture_finish_20261014/delivery.json`；原生同机位对照图库为同目录的`gallery.html`。桌面包为Apple Silicon/Intel通用，引擎仍为4.8-dev7。Web未随本轮更新。
