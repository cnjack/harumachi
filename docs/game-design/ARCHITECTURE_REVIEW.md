# 日式建筑与店内样件（2026-10-01）

这轮先在游戏里截图，再做三种局部构件和一栋完整建筑候选。目标是日式小镇里仍在使用的店铺：木构和白灰墙有明确的厚度，瓦檐能投影，陈列架像木工做出来的家具。贴图保持动漫平涂，木纹少而清楚。

## 实景里缺什么

- S01 晴町商店已有蓝瓦、二楼格栅和绿色遮阳篷，正面不是空白。较空的是侧墙下部、墙体与基础的交接；主建筑、箱子和商品被生成在同一块网格上，不方便分别整理。
- 商店和面包店的墙是简单盒体。原来靠 shader 画腰板、长押和天花边线，从斜角看没有接缝的厚度和阴影。店内墙高 2.8 米，却复用了住宅 2.4 米的天花边线参数，顶部木色过宽。
- 商店两排中央货架是奶白色的简单板框。四层商品高度和通道已经经过摆放检查，应在相同占地和层高内重做。
- 院墙与街区边界统一是水泥砌块，只有材质里的顶端色带。多段不同高度的墙共用一份材质，最终都把瓦帽位置写成最后一段墙的 1.6 米高度，0.7 米的入口矮墙尤其不对。

## 本轮已接入的局部改造

1. **商店与面包店室内**：Blender 构件 `P_shop_wall_frame` 补木柱、长押、压条和榫接肩。后门加有厚度的门框，暖帘分成四片。店内单独复制墙材质，把顶梁高度调到 2.73 米，腰板用新木纹。房间大小、商店出口、店主站位和交互点沿用原值。
2. **中央木货架**：重做 `P_gondola`，1.84 × 0.62 × 1.60 米；商品所在四层顶面仍为 0.14 / 0.48 / 0.82 / 1.16 米。增加木柱、端头横撑、背板条、价签槽和纸签。材质只有颜色与手绘木纹，金属度为零。
3. **S01 侧墙**：两块 `P_store_sidepanel` 挂在原建筑下面，木板、角柱、压条和石脚是独立几何。基于原 GLB 射线测量（侧墙 x≈±3.40 米）安放；原建筑和窗户映射保持原坐标。
4. **共享庭院墙**：六段院墙换成浅色灰墙与低石脚，并加有起伏、分片和出沿的蓝灰瓦帽、灰墙柱。街区其余边界仍使用原水泥砌块；各段材质独立，瓦帽按本段墙高计算。门洞与原碰撞位置不变。

三个 Blender 源文件与原始 GLB 在 `art/models/raw/japanese_joinery_20261001/`，生成脚本 `art/tools/japanese_joinery.py`。游戏版 GLB 通过 `game_export.py` 输出，配置在 `art/models/game_assets.json`。木纹原图 `art/references/architecture/20261001/cedar-grain.png`，运行用 1024 JPG。

## Hyper3D 完整町屋候选

CLI 使用已登录的个人钱包，提交一次 Gen-2.5-Medium，目标 40,000 三角面，启用 texture-delight。任务 `77a6de61-e574-4944-96b5-1b8e5eafb3b3` 完成，订阅积分从 15.5 到 15，使用 0.5 积分，普通余额保持 35。

- 原始 PBR 与 Shaded GLB：`art/models/raw/J01_machiya_hyper3d/`；导出选用 Shaded 颜色贴图，去掉金属高光。
- 游戏版 `game/assets/models/J01_machiya.glb`：39,955 三角面，约 1.88 MB，2048 贴图；尺寸 6.353 × 6.600 × 6.139 米（Godot XYZ）。底面倾角 0°，朝向误差约 0.02°。
- 在独立场景 `game/scenes/architecture_review.tscn` 和原商店并排，用相同游戏天空、光照、地面检查了正面、斜面、左侧和背面。正面朝 +Z，无需额外 yaw 修正。
- **仍是候选样件**。主街布局没有替换成它。它的屋顶、梁柱和木板墙比原模型更清楚，但底层玻璃仍是颜色面，屋后也没有日常使用痕迹；正式替换时需要重新测窗框，添加游戏橱窗映射，配独立遮阳篷、招牌和商品，验证店门与原交互点。

- Blender `level_check.py` 重测 153 个模型；本轮四个模型均水平、转正。
- 模型专项 PROPS 共 14 项通过，审查 398 个游戏内实例；无新增重叠、穿墙、悬空、陷地，原橱窗昼夜灯光仍通过。

- 新围墙回归测试先在原 `world_builder.gd` 上运行，发现 11 段错误高度，1 项失败；修复后通过。
- 随后按用户要求完成 macOS 打包：334 项完整回归通过，解压后完整自动演示 1222.5 秒、Q05 完成、退出码 0。`builds/HareMachi.zip` 已更新（约 592 MB），旧包保留。线上 Web 游戏未更新；完整町屋仍是独立评审样件。打包证据在 `evidence/package_architecture_20261001/`。
