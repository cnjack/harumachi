# 榕树下移动、澪步态与小葵日常（2026-10-12）

用户反馈的四处问题均在最新 `3f894bf` 源码上复核：榕树下走跑卡顿、下层枝条缺叶、作家澪步态和自动路线不自然、小葵站姿及所在位置生硬。拉取远端后没有待整合提交。本轮未重新生成付费模型，树和人物原 GLB、骨架及蒙皮保持原样。

## 榕树下的长停顿

同一原生实例在正午、1280×720、相同起点与方向下分别步行和跑步三秒；暂停游戏时钟及居民调度，关闭此诊断实例的 VSync，截图编码放在计时之外。隐藏苔藓、树冠或整棵树的可见网格都没有消除卡顿；只有关闭镜头碰撞才恢复流畅。原因是镜头的球形扫掠逐帧接触了树皮的 170000 个三角面。

现在镜头使用单独的 16000 面树皮碰撞资源。它由原生导入后的真实树皮减面得到，双面碰撞继续开启，玩家原有的两个树干/树根圆柱没有改变。3000、6000、10000 面候选未满足误差限制，未采用。32000 个可见表面采样的 99 分位误差为 2.79 厘米，最大 6.89 厘米；反向误差最大 3.42 厘米。另以真实物理射线检查 22 个方向和上轮曾穿入的树干位置，无漏击，命中点差最大 3.66 厘米。

| 同机原生短采样 | 修前 FPS / 帧中位数 | 最终复拍 FPS / 帧中位数 |
| --- | --- | --- |
| 树下步行 | 6.98 / 113.31ms | 87.61 / 10.88ms |
| 树下跑步 | 3.96 / 181.87ms | 92.55 / 9.99ms |

另在 Main、游戏时钟和六位居民调度均运行的原生实例中复测，步行 85.28FPS、跑步 89.12FPS，完整走出 5.35/11.02 米，游戏时钟实际推进。最终对照样本的帧耗时 95 分位分别为 14.98ms 和 15.48ms，镜头仍实际收缩避障。这是本机三秒样本，不代表所有设备、长时间游玩或固定帧率。修前物理更新因长停顿丢失部分位移，因此比较的是同输入、同墙钟时长，不能称为同距离基准。

## 下层枝叶

原模型的透明树叶主要从约 4.53 米开始；较低枝条只有烘焙的绿色团块。用实际树皮 UV 与原色贴图定位 175 个下层表面簇，再沿这些位置增加 516 簇小叶片，共 1032 个三角面。叶片使用原有透明叶枝图集，保留两个透光空隙和行走净空；最低约 2.31 米，没有增加任何人物或镜头碰撞。原深色树皮、树冠和八层绒毛苔藓保留。

来源与可重建数据为 `art/manifests/models_tree_locomotion_20261012.json`、`game/data/old_tree_lower_boughs.json` 和 `game/assets/collision/T05_bark_camera.json`。树下三方向及全景已原生复拍。

## 澪的步态与自动路线

`NaturalLocomotionPose` 仅修正澪的走路/站立，以及小葵的站立/说话。它放在原骨架动画之后、衣物和鞋底支撑之前；澪减弱髋、胸、手臂和腿部过大的摆动，膝盖向前弯，两脚维持独立的落脚通道，真实移动的支撑脚保持世界位置。鞋底检查复用启动缓存的小量极值点，没有在运行中重扫人物网格。传送、回家和动作切换会清理接触状态。

澪八个步态相位的实际渲染脚距由 3.7–8.8 厘米变为 15.4–15.9 厘米；支撑鞋完整鞋面离可见地面的最小间距为 3.1–8.9 毫米。澪行速为 1.25m/s，小葵为 1.15m/s，动画速度同步调整。保留其他手势和模型原始数据。

普通居民与活动试走共用完整胶囊扫掠规划：先测能否直达，遇障碍才懒加载 A* 的点和边；之后只移除能被完整身体直线走通的折点。空路一次扫掠即可返回，不再预扫整张网格。保留被占终点不可达、活动范围边界、取消与失败反馈。普通转角可在安全范围内提前朝下一段转向，起步加速、终点减速，避免每个格点停一下；同一会车对象保持第一次选择的绕行侧，减少左右摇摆。活动严格试走仍保留精确停点。首次包内演示发现平滑转向会让贴墙的严格试吃路线偏出检查线段，澪的试吃因而取消；新增贴墙直角回归先正常复现失败，再让严格路线沿已检查的方向行走，普通转弯继续平滑。长路线还发现普通会车推力会把严格试吃路线推偏，因此严格活动不再叠加额外避让方向，逐步身体碰撞检查仍保留；原40项试吃测试的首个步行样本扩展到真实公告栏，修前1项失败、修后全过，并在原生实例中完成试吃。
