# 起床后室内卡顿修复（2026-10-08）

问题在桌面版起床后的卧室走动中复现。大部分帧约8.3毫秒，但每过一个游戏分钟会出现约57–67毫秒的停顿。游戏时钟每秒推进1.5分钟，停顿间隔约0.67秒。计时定位到`GatheringView.sync_state()`：晚会尚未开始、没有食物时，也先调用`surface()`遍历桌面的渲染三角形。原生回调中位耗时63.148毫秒；关闭SSIL和体积雾没有消除停顿。

## 代码改动

- 先检查当天是否有未关闭的晚会食物，再测桌面支撑。第一天及其他没有食物的时间不再做这项几何计算。
- 桌面测量按模型实例、完整全局变换和桌面来源缓存。实例更换、移动、旋转、缩放或来源变化后重新测量；继续使用实际三角面和三份食物的盘沿支撑检查。
- 玩家与跟随镜头启用物理插值，位移及镜头角度都在物理帧写入。主场景其余分支保持原有更新方式。
- 记录玩家已经完成的物理位置，区分延迟到达的普通移动通知与外部传送。普通移动保留插值快照，传送和镜头`snap()`清掉旧位置。
