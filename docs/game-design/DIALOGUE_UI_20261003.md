# 对话画面清理（2026-10-03）

用户截图中，对话头像与小地图叠在一起，任务、时钟、快捷键和NPC头顶姓名也同时显示。检查发现四类问题：常驻HUD没有随对话隐藏；通知卡片和布置条不在HUD下面；对话中新来的奖励和成就会继续显示；3D姓名标签独立于屏幕UI。

## 修复

`GameUI` 新增 AmbientUI 层，任务、资源、时钟、小地图、操作提示、通知、布置条和章节横幅都放在里面。开始对话时隐藏整层；对话框、头像和选项在独立层，过场淡入淡出仍正常工作。刷新HUD或小地图自身更新不能绕过父层的隐藏状态。

`dialogue_begin()` 是幂等操作，连续调用不会覆盖原来的状态；直接调用 `say()`、`choose()` 也会进入对话显示状态。结束时清理选项和打字动画，释放当前对话的输入锁。原本被过场或截图隐藏的HUD、通知卡和NPC姓名不会被强制打开。

新奖励提示去重后排队，结束时补播；成就卡沿用最多两张的规则，收到后等到对话结束再创建。NPC姓名保存原本可见状态后隐藏，结束时按原状态恢复。圆形地图边框也改为从UI素材库取图。

## 验证

`--only=dialogue-ui` 的14项回归检查实际控件可见性、刷新期间隐藏、新通知延后及补播、原有隐藏状态、头像和选项、数字键以及地图/背包快捷键。旧工程有9项失败，修复工程14项通过。`--ui-demo --ui-dialogue-demo` 用真实鼠标推进台词、数字2选择第二项、E结束对话，检查恢复输入和通知补播；不替代真实剧情演示。
