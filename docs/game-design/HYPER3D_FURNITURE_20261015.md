## 实际支出与可重建来源

14张imagegen单体参考对应14次Hyper3D CLI Gen-2.5-High生成。钱包150→143点，实际结算7点，冻结0点，没有第二候选或重提。`art/library/hyper3d_furniture_20261015/provenance.json`逐件保存生成ID、原始GLB摘要、参考图摘要与原始质量判断；`exports.json`绑定27个游戏导出、来源组件及最终摘要。参考图、提示记录和不可变原始GLB随源码保留。

在`art/library/hyper3d_furniture_20261015/README.md`按顺序运行木作、玻璃柜、咖啡台准备工具及组合工具，可在忽略的raw目录重建可编辑Blender文件和中间GLB，再通过`game_export.py`导出本批27个ID。这条重建流程不调用付费生成。

## 形体、材质与玻璃

12个木作单体保留原三角面数量、UV坐标与图集RGB像素，只拟合尺寸、实际承重面、脚底、弧背和墙架后背。修承重面时同步位置相同的UV接缝副本，避免板面裂口；没有新增隐形承重代理。两种椅子的前后背皮都测量弧度与扭转，脚印朝向转正；长工作台沿实际长边拟合，腿端宽度保持。

原始14个输出都是带不透明图集的单网格，玻璃不能直接使用。蛋糕柜保留生成柜体和木框，局部切掉不透明窗面，配5块独立6毫米薄玻璃；66条正向、30条侧向通透射线及18处真实层板支撑点通过。咖啡机保留生成的机身、磨豆机和柜体，只修豆仓为闭合3毫米薄壳，豆子贴着真实料堆。玻璃保留随视角和灯光变化的克制反射，减少多层白色叠加，柜内商品和咖啡豆保持可见。

14个单体的原图集RGB像素全部一致。木材、涂装、钢材、铜件、橡胶与布面分别处理；扶手、桌腿和椅背更哑，桌面与座面按使用区域增加轻微磨耗。相同椅子共享实际网格数据，六人桌导出从11,797,388字节降到8,486,564字节；两个版本本来都只有2张图集，不能把缩小归因于删除6张图片。

## 复用与实际摆放

实测100组家具摆放，包括58处按尺寸适配的桌台/长凳、40处组合家具和2处直接单体。组合家具计一组，不是100种模型。58处包括38个工作/置物台、8个低桌、12个室内长凳；原9处户外长椅、10把阅读椅、6个矮书架及两店货架也使用这批来源。原商品、暖桌布和书籍按用途保留。

不同尺寸的家具缓存按实际网格资源区分。墙架后背要实际接触真实墙面，离墙10厘米的反例必须失败。烘焙店花草台移开回收台，商店篮台避开菜箱与冷柜，莲的打包台加深以同时承托托盘和纸张；撤下3个已被新座位占用的重复坐垫。试吃餐盘、茶壶和纸包移到实测完整承重面。户外座高按实际偏置坐点测量，湖畔纪念册和原花火剧情入口保留。
