# 小地图、图标与手绘界面（2026-10-03）

小地图改成朝北的圆形地图，外缘羽化，叠加 imagegen 生成的和纸圆环。标题和目的地是独立的小胶囊，不再用一整块矩形卡片包住地图。玩家方向保持红色，目标使用金圈；目标在画面外时，箭头沿圆周内侧指向它。地图可以点击，也可以按 M 展开。

全地图有晴町与水岸两页。商店、面包店、花店、邮局、公民馆、农园与四个钓点使用手绘图标，可以点图标或地点列表标记目的地。跨区域目的地先指向实际出口；到另一区域后继续指向所选地点。距离是直线距离，不表示沿小路的实际路程。清除手动标记后恢复委托指引，标记只保存在这次游戏会话中。

地图的建筑轮廓读取实际模型的世界包围盒，水面和小路沿用 LakesideLayout。标记的位置与世界交互点一致，农园使用本地坐标，并在需要时加上 FarmBuilder.ORIGIN。

## UI 与图片

HUD 将委托、金币与种植进度拆成紧凑区域，时钟单独突出时间。底部六个按钮保留快捷键并支持鼠标点击。地图、背包、商店、委托、日历、图鉴和对话框共享更轻的和纸风格，文字仍用霞鹜文楷。

共生成两张透明图集，包含 24 个导航、天气、资源与菜单图标。随后按用户反馈生成三张背景：

- `modal_paper.png`：大弹框和纸、细金线、灰绿外缘与角落银杏装饰。
- `hud_paper.png`：小胶囊背景、轻纸纹与柔和外缘。
- `minimap_ring.png`：中心和外侧透明的圆环，带方位刻痕与细叶饰。

图片在 `game/assets/ui/refresh_20261003/`。原 PNG 的 alpha 和像素保留；运行时按量测区域取图，缓存用于绘制的等比纹理。大面板采用九宫格伸缩，窄条使用更小的角区，避免上下边片重叠。内容留白另外计算，不能直接把图的透明边距当成文字间距。九宫格行为参考 [Godot 4.7 StyleBoxTexture](https://docs.godotengine.org/en/4.7/classes/class_styleboxtexture.html)。

图标用 AtlasTexture 取原图区域，没有按颜色抠背景。提示词为 `art/manifests/prompts/ui_refresh_20261003.json` 和 `ui_frames_20261003.json`，来源与摘要写入 `art/manifests/images_codex.json`。绘制区域和透明度量测分别保存在 `evidence/ui_map_20261003/icon-survey.json`、`frame-survey.json`。

## 操作与验证

`--only=ui-map` 有 24 项检查，覆盖图标透明区域、生成背景实际接入、圆形命中区域、标记边界、坐标转换、跨区域出口、输入锁、目的地清除，以及 1280×720 / 1600×1000 / 1920×1080 的布局。旧版本在其中 21 项失败，原有三项全地图尺寸检查仍通过。

`--ui-demo --ui-demo-out=<目录>` 为可重复的视觉验收。起始物品、天气和位置是显式测试条件；点击小地图、切换地图页、点击钓点、清除标记、打开背包和关闭界面都经实际鼠标和键盘输入。等待加载遮罩关闭后再发输入，避免把遮罩拦截误判成按钮故障。输入转发参考 [Godot 4.7 Viewport](https://docs.godotengine.org/en/4.7/classes/class_viewport.html)。

录像不是必须；本轮保存昼、夜、雨天、地图、背包和其他面板截图。全量与原生包验证结果以 `evidence/ui_map_20261003/verification.json` 为准。默认 ZIP 只有在冻结工程、解压应用交互演示和原完整剧情演示通过后才更新，旧包另留备份。
