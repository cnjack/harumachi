# 时针、停车公交、猫和六个存档

这轮落实试玩反馈：钟面只保留时针；公交缩小、车窗通透、到站停车，司机可对话；三只环境猫能按 E 摸并喵叫；保存和读取最多六个独立位置；水流与植被风动画重做。树与免费素材库见 [院子老树](HERO_TREE_20261005.md) 和 [3D 素材库](ASSET_LIBRARY.md)。

## 具体行为

钟面用独立文字和刻度，只有时针；仍按分钟连续推进时针角度，10:30 在十与十一之间。公交保留到站、开门和下车演出，随后一直停靠，四个车轮恢复拟合车身时的原始姿态，避免停在生成网格旋转后的歪斜轮廓。旧存档恢复时也停车。司机对白明确当前不能乘车出村，没有开放村外场景。

Hyper3D Rodin 的高质量公交和两只猫原始模型保留在 `art/models/raw/scene_polish_20261004/`。公交拟合到长 4.6 m、宽约 2.05 m、高约 2.14 m，拆出轮、门与真实窗洞，九块独立玻璃面透出内部。猫游戏模型各约 120,000 三角面，保留 4K 颜色贴图；减面前先焊合 glTF 在 UV 接缝处重复的几何顶点，保留每面 UV，避免简化后碎裂。坐猫按实际墙帽支撑面放置，不能再用统一墙高。

按 E 摸猫直接播放短动作和合成喵声，不打开对白。现有睡猫呼吸、坐猫头耳动作保留。这里不把局部动作称为完整四足骨骼动画。

## 水面算法

河流与湖面共用 `water_motion.gdshaderinc`。河纹沿河道弯曲方向平流；两路相差半周期的噪声在重置前交叉混合，避免每八秒突然跳回起点。三组小振幅 Gerstner 波提供解析坡度，在像素阶段求法线，避免大网格三角面显形。保留手绘天空色、岸边浅色与细泡沫，不添加高强度写实镜面材质。湖面使用较缓的波动，河流沿弯道流动；`animation_time` 仅供确定相位的截图检查，正常运行用 TIME。

## 六个保存位置

SQLite v4 存储位置和游戏数据版本保持不变。新增 `save_slots` 表，槽位范围强制为 1–6，各自保存完整快照、日期、时间、金币和校验摘要。旧 `current` 或可恢复的 `previous` 一次性迁入第一个槽位；已经迁移后不重复生成槽位。

标题的新开局和继续、暂停里的保存和读取都显示 2 × 3 位置卡，支持键盘与鼠标。覆盖已有位置需再次确认；损坏摘要不覆盖当前游戏。设置仍为全局设置。换槽位后重建当前/前次恢复链，避免读取另一个人物进度的 previous。每日结算仍在 `advance_day()` 完成后只写一次，保存失败显示错误。
