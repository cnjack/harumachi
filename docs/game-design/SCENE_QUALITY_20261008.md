# 场景材质、牌面与声音修订（2026-10-08）

本轮落实墙面、桌面、木牌字体、室内用途和画风统一性的检查结果，也补齐实际声源定位与餐桌声音。复用已批准的手绘纹理和现有模型，没有提交收费图片或3D生成任务。

## 牌面与指引

黑板前原来的纯绿盖板已删除。Blender射线量到前板约12°后倾，颜色只重绘原模型的内侧板面，保留木框、钉头和脚架；文字随实际板面倾斜。价格直接读取商品数据：试做菠萝包40、奶油面包42、草莓甜甜圈45，删除没有对应商品的咖啡菜单。

方向牌保留原生成木柱与根部植被，去掉相互遮挡的旧箭头，换成有厚度的手绘木牌。统一字距，正反两面都有文字。木柱朝西，商店街与农园先向北回主街，住宅支巷向南；农园补充“沿主街向东”。检查读取实际箭头网格尖端并转换到世界坐标，不只检查字符串。

## 表面与房间

W13工作台、蛋糕柜木框、品评长桌和供台共用`painted_finish.gdshader`，按每个分件的长轴定木纹方向；玻璃保留原透明着色器。家中餐桌只重绘台面，椅子等原图保留；客厅布面改成浅绿米白的夏季配色。木地板保留板缝和板间色差，去掉原密集黑色小点；墙面和室内地板按商店、面包店、工作间分别调色。

商店有米粮/调料、园艺和日用标签；面包店区分烘焙区、甜点柜和面包陈列。工作间增加旧会场简图、分类档案、备用竹条、现有模型材料箱和试样和纸。小桌补齐四腿，档案架补立柱。牌签贴到货架、桌围板、箱体或墙面，删除原来悬空的三个说明。家中生活便笺贴在碗柜上，墙体切低时仍依附家具。面包店合作纸签有独立木架与真实碰撞，原互动停点保持不变；室外合作指引改为近距UI提示，避免把悬空文字当实体牌。

试挂净空、旧账本互动、产品支撑、现有门口和店主路线保留。工作间首次进入不伪造已做好的灯笼；制作阶段仍由原剧情状态显示同一件真实作品。

## 光照与声音

室内体积雾密度由0.011降至0.0065，间接光强度由0.9降至0.65，减少发白的罩雾，保留金色窗光和淡紫阴影。没有提高阴影分辨率或加入新的全屏特效。

玩家有独立听音节点，方向随游戏镜头变化；室内俯视镜头的高度不再改变附近人物、风铃与交互声的距离。12个复用声源提供18米范围的声音定位；室内给Foley总线少量混响，UI与配音保持清楚。进出门、挪托盘、部分取放与浇水使用场景位置。

新增餐具落桌、饮茶两组本地合成音，各有四个固定变体。挪托盘成功落定后才响；吃饭变空盘和饮茶动作达到55%时播放自己的声音，取消演出不会提前播放完整完成声。
