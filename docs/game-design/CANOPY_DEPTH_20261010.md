# 广场树冠、苔藓与墙外景观（2026-10-10）

用户指出墙外杉树和单色地面出戏，老树树冠没有层次、透不进阳光，树皮还不够沧桑；苔藓需要细密的绒面。这轮沿用已有 Hyper3D 枝干，没有新增付费 3D 生成。

## 最终画面

老树从连续的圆顶改为九组高低错落的扁冠，叶簇之间留下透光通道。叶卡由 4200 张减至 1900 张，枝干依然外露；整树约 12.441 × 9.078 × 10.426 米。树皮颜色压暗，保留原来弯曲的枝干、裂纹和树结。

苔藓贴着实际树皮分成八层，表面高度为 1–22 毫米，越外层越稀疏。短绒主要留在低根和潮湿凹处，深浅苔色之间保留裸露树皮。模型有 310208 个苔藓三角面，18 米外淡出。它需要 `WorldBuilder.make_sway()` 配合 `moss_pile.gdshader` 的三向贴图和透明绒毛材质，通用 GLB 查看器不能还原游戏里的效果。素材库使用原生游戏截图作为预览。

杉树保留 CC0 Quaternius 木质枝干，整类替换成 1922 簇独立针叶，补齐较低的侧枝。四个墙外地面区域改为有色差的草地，加入 6589 簇草和不规则矮灌木；东侧有缓坡，植被高度和实际地面碰撞共用同一网格插值。去农园和西侧道路保持通行。
