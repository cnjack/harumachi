# 食物去向与杯边下一餐 · 2026-10-06

本轮延续抽象吃饭：食物在桌面出现，停顿后留下空盘，接味道与心情对白。吃饭不依赖角色抓握或送到嘴边。原有首餐、普通进食、预留和库存规则沿用；新增杯边入口也使用同一演出。

## 可玩的去向

夏祭或明确重约的新篮仍只有三份。可以保持公共招待，也可以当面给春留一份配麦茶、给莲封一份等他忙完来领，或收一份回家。两种备法分别显示沥汁分小片的纸包和保留汁水的托盘；改变备法不增加食物。

春从公共桌实际领取后，沿当前碰撞路线走到麦茶角，把同一份放在杯边空面。中断时保持“已领、未放好”，下次见面可以继续。安放不是吃过或喝完；只有安放完成才开放相应回访。昨天的安放记录保留，食物不会永远堆在今天的杯边。

回访可安排自己的下一餐，也可暂缓或不安排。已有盐饭团配方后，用正常米盐在灶台做一批两份；这个便笺只制作一次，普通配方仍可自由使用。尚未学会时不凭空授予配方。专用制作行只在明确意向后出现，制作后移除。暂缓可在春、麦茶或完成首餐后的碗柜主动重选；不安排不会被自动重开。

自己的饭可以在家吃，也能在春实际来到茶角时带去吃。家吃不自动让街坊知道。共同知情与当次消费绑定，不能在之后碰面时把以前私下吃的饭改写为一起吃过。首次集市的莲回访只让玩家说出实际递给谁、打包多少或自己吃过；选择不说则不增加他的知识。

## 恢复与份量

新篮才有三个份量 ID，旧记录不补写新备法或用途。具名份不会被其他人拿走；已经领取的人不能再预留同篮第二份。散场把尚未领取的余量打包，不复制春已领的份量，之前自留的一份也计入总打包数。

下一餐选择提交并保存后才标记回访完成。选择菜单退出时，读档仍能继续决定。制作界面先保存本次产出，再提交制作；配方行消失后仍正确显示“自己下一顿的盐饭团 ×2”。
