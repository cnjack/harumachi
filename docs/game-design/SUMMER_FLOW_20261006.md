# 从试营业到花火的连续过程

2026-10-06。继续完整夏季目标，不将局部规则通过当成自然四小时或75分通过。

## 这一轮的玩法变化

首次集市结束后，奶奶的箱子成为可主动打开的邀请，不必为了开放箱子先过一个空夜。每天生活事件仍不自动接受；玩家可以继续自己的安排。

盆舞前可选择在舞台旁歇到八点，或继续逛。休息只推进明确的时刻，不算已经参加；实际盆舞结束才提交参加事实。花火结束恢复参加前的站位和镜头，避免玩家留在长椅碰撞中。

花火或晚来听记录后，可以选下一步打算：种点菜、一起再开摊、以后回来、慢慢再想。四项没有奖励高低，也不开放尚未制作的季节。意向是实际选择，保存在SQLite，并以便笺出现在家中真实书桌上；旧完成存档不倒填便笺，之后可从书桌主动写。取花火筒时，田中不在场就读活动纸签，不播放他仿佛正在旁边说话的版本。

## 灯笼的两种可用安排

通道、支架和观察点固定，玩家选择通道上方或侧边的吊点。原低通道位依然会碰头；低侧挂可留出通道，从近处看纸面，来路却可能被晾纸架遮住。高通道位留净空，从来路认灯容易，近处需要抬头、字面角宽较小。高侧等其它实际有效组合也允许，不为凑两个答案强行拒绝。

检测使用最大使用者的0.32米胶囊、头部净空、近观察点可达路线、灯体/纸面两类射线；反向纸面不会被说成灯体消失。碰头失败可挪侧边或升高；正确初案能保留。晾纸架/活动安排纸架在选择前已经存在，不随挂法才出现。观测菜单提供明确的近/远观察镜头，不把镜头移动记录成人物走近。

同一作品的图样、接头、材料和作者保持。变挂处使当前试用/安装重新检查，历史仍留；旧档缺吊点默认为原通道位，不能推定玩家曾主动选过。收回后可直接重新挂到试架观察，不重选原参数、不重扣材料。

原生`--lantern-choice-demo`实际选择两种挂法、测量、保留与四个观察镜头。站位/Q11是声明的夹具；实际画面见`evidence/summer_flow_20261006/lantern-reviewed/`。首批13项与后续18项相关检查通过；最终967项全量、0失败、无SCRIPT ERROR；全程fresh证据另记录。

## 完整自动演示的证明边界

`--autoplay`的新cooperation路线由真实新游戏起步，经首餐、两位试吃、实际桌椅/路径、首次集市、主动旧箱与账本、键盘接头、试挂、真实邀请日历、夏祭菜单再用/同灯/实际领取、盆舞/陪看/明确照片、收尾与花火，到家中读便笺。

新的驱动只走实际碰撞路径并确认目标可交互，不直接写任务或项目完成，也不使用旧驱动的25秒瞬移兜底。角色胶囊包括矮家具，区域切换后旧路径停止。时钟暂停、对白自动推进和游戏本身的过场切镜都明确声明；它证明技术覆盖，不能用来计算真人时长。

`--autoplay-resume`只用于加载真实隔离存档调试后半段，记录起始摘要、slot、sha256和fresh_run=false；不计为新游戏全程通过。预约要验证实际日期/时刻和保存成功，花火延迟结尾要等回调开始并恢复控制。只有fresh完整结果可以进入导出包验收。

最终fresh演示已通过204项过程断言，退出码0，Q15完成、实际花火、收尾、家中便笺和控制恢复均成立；elapsed约938秒是暂停时钟/自动对白的技术演示时间，不是自然玩家时长。记录在autoplay-fresh/report.json。最终967项单独全量、0失败、无SCRIPT ERROR；之前带SCRIPT ERROR或目标失败的记录保留为失败诊断，不拼接为全程。四小时自然容量、按对象的备法/去向、生活陈列、两条普通完整组合及两份整篇75分审核仍未通过。
