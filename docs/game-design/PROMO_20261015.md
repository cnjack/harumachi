## 动画与配乐

八张关键帧、原生参考图与提示词分别保存在`art/references/promo_20261015/`和`art/manifests/prompts/promo_20261015/`，登记于`images_codex.json`。人物镜头还引用游戏原有头像，保持发色、衣着和脸型。最终八段H3片段采用FL2VA，输入为PNG内容的data URI，沿用服务端模型与采样配置，不调整LoRA；`quality=lossless`、`output_compression=80`。任务编号、参考图、提示词和源文件摘要写入主片清单。

首轮只有轻微呼吸与镜头推进，用户指出人物不动，已弃用于主片。最终动作包括桥上行走、走到告示栏前、伸展双臂、烘焙师招手并转向烤炉、蹲下查看番茄后起身、完整抛竿和浮标落水、抬纸包灯笼，以及夏祭相互招手。桥景原文件4.458秒，取前4秒；其余七段各8秒。每段以0.5秒间隔抽帧检查，共120个源动画帧；记录在`animation-reviews.json`。轻微运镜与生成细节变化仍存在，不声称每个像素完全一致。

下载断流时按已有任务编号续传，校验HTTP 206、Content-Range、分段长度、总长度与摘要，再完整解码；不因传输问题重生成。被前置查询超时拦住、未返回任务编号的提交，均先核对已有任务后处理。

原配乐96.119秒、44.1kHz双声道，无削波或长段静音。使用保音高的约1.068倍速度匹配90秒，混入少量实际游戏效果声，CG生成音轨不进入主片。最终混音实测−15.45LUFS、−1.34dBTP；声部分离的人声热区0秒，AST的人声干轨/混音最大分值0.09/0.02。工具不支持主观听感评价，未声称实际听辨；音频文件保留供试听。

## 整片验收

成片90.000秒、1920×1080、30fps、2700帧，AAC48kHz双声道。完整解码通过，56个关键时间点覆盖所有镜头、16个转场、开头和片尾。字幕、CG/实机标签、人物动作、画面连续性与片尾已复核。

影片与源码发布的完整审计为`evidence/promo_20261015/delivery.json`；仅影片的预提交审计为`delivery-media.json`。最终提交、远端核对与CI结果记录在`final-source-push.json`。所有证据均在本地`evidence/promo_20261015/`。

## 复用流程

```bash
python3 art/tools/record_promo.py prepare --out <独立证据目录>
# 建立临时虚拟屏幕后实测屏幕编号和Godot像素坐标。
python3 art/tools/record_promo.py story --out <独立证据目录> --screen <编号> --position <x,y>
python3 art/tools/record_promo.py scenic --out <独立证据目录> --screen <编号> --position <x,y>
python3 art/tools/record_promo.py lake --out <独立证据目录> --screen <编号> --position <x,y>
python3 art/tools/record_promo.py finish --out <独立证据目录>
python3 art/tools/download_promo_video.py --out <已有任务目录> --workers 2
python3 art/tools/review_promo.py <视频> --out <复核目录>
# 八段源动作经视觉复核后批准清单，再导出并复核整片。
python3 art/tools/build_promo.py
python3 art/tools/verify_promo_delivery.py --media-only
# 完成项目检查、提交、推送和CI后执行最终审计。
python3 art/tools/verify_promo_delivery.py
```

`review_promo.py`只输出完整性数据与未修饰抽帧，不自动判断动作是否合格。`queue_promo_video.py`要求已有动作样片通过视觉复核；补录批次单独保存记录，桥景可用`--names bridge`。新一轮须更新素材、任务记录、清单和视觉复核，不能套用本轮摘要或旧录像帧号。视频、录制原始文件、任务状态与临时工作保持本地；提示词、参考图、资产清单和工具进入版本管理。
