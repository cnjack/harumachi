# 合作试吃与空摊位（2026-10-07）

合作仍只有一批三小份和两位用途意见。第一位在已有实物台面旁选纸托或餐盘，两人通过碰撞行走到不同停点，再看真实餐点变为空托。第二位在原处收下一小份，参考这一批已经发生的第一意见，补充河边休息、配茶分食或换班取餐的用途，不强制第二次赴桌。第三份仍可自留，喜欢第一菜单可直接保留，不增加必做烤制或取送。

`usage_feedback` 记录实际桌边试吃的菜单、盛法、生活用途、人和日期；`received_feedback` 记录收下一份后的用途意见及所参考的人。旧档的原试吃人数保留，不补写成新演出。纸签分别说明两种事实。

取消、缺席、台面失效或新物占位不扣份；镜头、输入锁、玩家冻结/自动方向和居民速度/日程统一恢复。赴桌从实际位置继续，玩家规划包含 L_BLOCK。保存失败回滚该份、该人、该意见与阶段，恢复存储后可重试，不播放成功意见。

原面包篮改用实际柜台高度及八个盘沿支撑点，不能保留原来的0.525米台面常数。晚会三份和包装演出也测量当前柜台；P09右侧留给这三份、左侧面包篮分开。野餐桌含周边长椅，其整模宽度不能代替桌面长轴：按实际三份盘沿支撑选择排放方向，转90度后也重新测量。
