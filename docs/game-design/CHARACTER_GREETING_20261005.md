# 招手、微笑与手部比例（2026-10-05）

七人的招手掌心已转向被招呼的人。空、莲加入轻微闭嘴笑；澪、春、田中、小葵、和子保留原有固定表情。根据用户指出的手掌显大问题，空、莲、春、田中的双手和手指整体缩小 10%，其他三人维持原尺寸。

## 掌心方向

原动作让掌侧朝前。仅调整 wave 的右前臂、右手旋转，采用前臂转动承担约 80%、手腕补偿其余部分的方式。手腕额外转动不超过约 30°，抬手位置和原动作时长保留。起止阶段平滑回到垂手姿势；站立、走跑时依旧掌心朝身体。NPC 原有 face(player) 会转向被招呼的人，所以角色前方就是招呼方向。

独立 Blender 检查使用实际蒙皮后的掌面多边形，覆盖七人、招手中段 23 个时刻。旧莲掌面朝前点积最低 -0.142，回归实际失败；修正版七人最低均高于 0.90。不能只检查骨骼朝向，也不能把关节本地 Y 一律当成人体手掌长轴。

## 手部大小

掌心完整露出后，原有的宽手更明显；转手操作本身没有增大网格。逐人对照中，莲和田中相对头部最显大，空和春略显宽；澪、小葵、和子保留原比例。以腕部为中心统一缩放 Hand 与整个手指层级，保留原有腕部权重过渡，不只缩小掌面。

实际蒙皮点云回归测量双手在 idle / walk / wave 的三个时刻，四人表面尺寸比约 0.9000–0.9002。缩小后的招手、走路、跑步、腕部和袖口已经用实机图复查。原网格位置、UV、贴图、原有修形、骨骼名称和原 11 动作时长保留；这里通过蒙皮变换调整可见手部尺寸。

## 微笑自然性

空与莲仅抬嘴角最多 1.5 毫米，不改变眼睛、鼻子或张嘴结构，招手时逐渐出现，再逐渐收回。正面、斜侧面和没有手臂遮挡的侧面做了近景比较。其余五人的原表情已经带笑，保持固定表情。

莲初版表情曲线只保留首尾，微笑几乎没有播放出来；修正为密集采样并补齐 0 秒的中性起点。实际 Godot 回归必须检查峰值播放与走路取消招手后的恢复，不能只看模型包含一个微笑修形。

## 八角度美术复核与贴图升级

按用户要求补拍七人站立、招手、走路的全身、面部、右手近景，正、背、左、右、俯35°、仰25°、上75°、下60°，共504张实机图。按轮廓、五官与视线、手部厚度与比例、衣褶衔接、颜色一致性看图。空的肩缝有锯齿状白缝，小葵的掌心有明显橙色色块，不能用数值回归通过代替美术验收。相册文件以人物名加artist-body / artist-face / artist-hand命名。

七人当前贴图均为2048×2048 PNG。Hyper3D官方已有模型重贴图接口支持texture_mode=extreme-high、resolution=High输出12K，文档收费2积分。当前配置的MCP只提供生成/拆分/下载，缺少重贴图与12K参数；它的OAuth凭证调用公开API余额接口返回401，不能据此认定账户需要升级。网页尚未登录，12K试验等待登录或正式API凭证；没有新付费提交。方案文件为texture-12k-poc-plan.json，输入原模型与批准参考图，输出只作为贴图候选，先验证UV、几何和原动画保护，再做八角度实机对照。官方来源：https://docs.hyper3d.ai/en/api-specification/generate-texture 、https://hyper3d.ai/pricing 。
