# 商店与面包店的陈列、招呼和工作（2026-10-06 制作，10-07 验证）

商店增加日用品、农产品、园艺工具和独立熟食台；面包店保留原来的六种立体面包，再增加奶油面包、草莓甜甜圈和蛋糕。两位店主会招呼进店的人、走到工作位置整理，再回到柜台。海报和电视画面使用 imagegen 插画，文字由游戏字体绘制。

来源与任务 ID 在 `art/manifests/models_hyper3d_shop_20261006.json`；原稿在 `art/models/raw/<ID>_hyper3d/`；参考图在 `art/references/shop_life_20261006/`。10 次 High Raw 生成按每次 0.5 积分估计共 5 积分；同一账户同时有其它任务，不能把整个钱包变化归到本批次。已接受的任务只轮询和下载，未因查询失败重复付费提交。

原 I02 蛋糕柜的大片不透明板遮住蛋糕，已用 `rebuild_cake_showcase.py` 重建木框、实测层板和薄玻璃，保留原外尺寸与占地。玻璃在 `HouseBuilder.toonify()` 后逐面覆盖 `shop_glass.gdshader`；不能同时叠加整节点材质覆盖，否则出现 material-null 日志。

三张海报和两张电视插画的原提示词、原始输出与文件摘要登记到 `images_codex.json`。食品图标由实际模型渲染成透明 PNG，归入统一 UI-kit。素材室索引和十一件模型的网格预览已更新。

## 场景行为

`ShopContent` 从实际三角面测量支撑高度，每份商品保存对应支撑节点与层高上限。多层货架不能向整件家具最高处查询；摆放普查按物体真实高度区间判断相交，避免把上下两层蛋糕误算成重叠。熟食台位于商店 `(1.85, 0, 3.0)`，使用缩至 70% 的 W13 工作台，入口和店主路线保持可通行。海报挂在木框向室内的一面，避开凸出的横梁。

午后陈列减少，店主整理后暂时补满；这是时刻与工作动作驱动的视觉陈列，尚未逐份绑定购买库存。货架上的包装商品和工具是展示组合；四种新食品和原草莓蛋糕已接入实际商店购买、背包与实体餐点映射。

`ShopLife` 按营业时间、店主在场和玩家位置播放欢迎语，同一家店至少间隔 45 秒。已有剧情、对话、配音或界面操作优先；店主工作时用实际碰撞路径行走和原有整理动作，完成后返回精确柜台站位。剧情强制调度、搭话或离店会取消工作，不持续抢占店主位置。

和子与莲各有早间、稍晚两句欢迎语，使用原配音选角；四句语音的识别 CER 为 0，停顿检查通过。语句保存在 `game/data/shop_life.json`，生成器可用 `--include-file` 只处理这个文件。

电视每 12 秒切换镇上与河边农园插画，叠加轻微画面移动和扫描线。天气频道的标题读取当日天气，雨天增加雨线和冷色；闭店时待机。它是两幅动态插画节目，没有加入电视视频或额外广播配音。

## 验证与复现

新增第一批六项检查先在旧场景上全部失败。最终商店专项 24 项覆盖实体商品、真实支撑、分层相交、门口净空、营业与雨天电视、欢迎语节流、剧情优先、工作往返、补货、实际扣款和食品图标/模型。摆放专项 46 项通过。最后海报挂点调整后，独立冻结副本 1227 项全量通过，退出码 0、无 SCRIPT ERROR；每秒检查没有其它 Godot 实例同时运行。完整结果在 `evidence/shop_life_20261006/verification.json`，保留既有资源退出提示和故意破坏数据库的测试日志。

全量与录像绑定最后冻结副本；随后其它工作调整了三个剧情文件的叙述台词，已保留差异，并在当前开发工程重新跑过24项商店专项。本轮商店代码和模型与已验副本一致。

原生 Godot 4.7.2 Forward+ 录像约 42 秒，包含实际游戏音轨；时间采样证明两次欢迎语、两次工作往返、两次补货以及店主位置变化。实际近景覆盖食品、三张海报、商品架、工具架、电视晴/雨画面和两间店。录像是固定日期与镜头的视觉验证，不代替完整剧情或自然连续试玩。
