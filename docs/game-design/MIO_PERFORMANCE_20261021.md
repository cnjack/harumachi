Swift 开始读取同包 `motion3`、`exp3`、`physics3`。动作曲线支持线性、Bezier、阶梯和反阶梯；当前四动作使用生成的标准曲线。思考保留跟随下巴的交互求解，切换保留手部速度约束。物理输入、输出、粒子和归一化来自 physics3；不再用渲染器内硬编码的旧头发弹簧。原 `HairPhysics` 保留用于旧回归对照，不在当前生产渲染路径调用。

六个眼口网格在源 CMO3/MOC3 中使用脸部 alpha 剪裁。Metal 先绘制遮罩，再绘制正文，支持普通/反向遮罩；缓冲区循环复用并限制在途帧。反向遮罩测试模型独立导出到临时目录，眼区与正常模型差 27.74/255，确认裁切实际生效。正常、加法、乘法混合管线均已实现，本轮真实资源验证的是普通混合。

网页 ZIP 包含 15 个 model3 引用文件、说明和可选 `mio-performance.js`；不含厂商 Core。该适配层提供 `welcome / quiet / waiting / reply` 与五种表情、180 秒欢迎冷却、文字口型及非固定重复的眨眼/视线；不使用适配层也可直接用第三方兼容播放器加载标准模型。

验收结果：

- `swift test`：73 项，70 通过、3 项可选网络集成跳过；另用真实 Clef 完成七轮角色、时间、工作、追问、安静、恢复、庆祝对话，684 个原生渲染帧。实际返回的 mood/intent 写入记录。
- 官方 Core：29 个有效参数、30 ArtMesh、2060 帧、37 张渲染。45 个脸部组合和 1680 个情境帧另验。
- 5210 帧接缝：52100 个中心采样最小 alpha 253，无低透明和裁边样本。肘/腕最大几何接合差 0.000137 px；30 FPS 最大腕部单帧移动 19.404 px。逐组查看四动作关节近景、全部切换及视线极值表。中心透明度不能单独证明轮廓自然。
- 原生独立窗口：28.064 秒、1667 帧，平均 59.40 FPS，五个捕获状态检查全部通过；不启动监控、网络、音频或虚拟显示器。
- Pixi 6.5.10 + pixi-live2d-display 0.4.0：174.6 秒、10470 帧，约 59.97 FPS，情境流程、八次切换及五种表情均完成，无页面错误、手型交叉淡入 0 帧。
- `python3 tools/check_project.py`：8008 项通过。原桌面来信包内运行资源与本轮源资源逐文件一致，已结束旧进程并重启同一应用。

证据入口：`evidence/mio_performance_20261021/verification.json`，网页包 `Mio-live2d-web.zip`。可重复入口：`--review-performance`、`--review-cubism`、`--review-motion`、`--review-motion-window`、`--review-dialogue`；网页口型对照用 `node native/mio-companion/tools/verify_web_performance.mjs <performance.json>`。

本轮保持原眼睛素材，不恢复用户否定的 v15 新眼部切片；小角度转头适合当前素材，不包含侧脸重绘。文字口型没有生成语音，也不宣称音素级口型同步。Swift 与网页使用同一参数文件，但物理积分和切换调度不同，未承诺全身和头发逐像素一致，也未宣称支持任意第三方模型。重启后的常驻主窗口受 Mac 锁屏影响，尚待解锁目视复核；本轮独立可见窗口和真实对话窗口已完成实际播放。新的长相和自然度仍以用户复看为准。
