# 普通原生试玩发现的引导问题

2026-10-06。独立审阅者从标题读取已有第一天进度，只通过游戏界面阅读和选择。没有读源码或设计答案，也没有修改时间、材料、位置。此次观察到公告栏、手账、合作追踪、地图和日历；尚未到店、完成合作或跨日，不能当作完整首日、真人意愿或四小时容量证据。

## 公告栏

搬家后再次看公告栏，旧版仍用三项清单表达准备情况，容易把社区帮忙理解为合作主线的必要条件。新版按当前存档路线显示：新合作路线先写当前合作的下一步，再明确列出可选社区帮忙；旧档继续保留旧路线清单。合作进展改变后，公告同步显示新的实际阶段。

新入口检查使用实际 Story 交互和可见通知。修改前16项中2项失败，修改后16项通过；当时全量1080项通过。独立审阅者在原生导出包中看到了面包店合作纸签、试做/安排取餐两种方式，并自行在手账追踪合作。证据在 `evidence/board_revisit_20261006/` 和 `evidence/native_ordinary_review_20261006/`。

## 日历

原生画面中7月4日的HUD写周四，日历却把当天放在周日列。原因是月初比游戏第一天早，负数游戏日被通用 weekday 接口当作“今天”的默认参数。日历现在单独按游戏起始星期计算全部日期，保留通用接口原有语义。

回归比较实际格子的列：7月4日周四、7月6日周六集市、7月7日周日、8月5日周一。修改前28项中3项失败，修改后28项通过。原生图像复验另记，不以规则检查替代实际画面。证据在 `evidence/calendar_grid_20261006/`。

## 地图

原生地图的店铺标签互相遮挡，右侧地点列表仍可使用。旧布局在碰到一个标签后移动一次便停止，没有检查移动后是否碰到其他标签。新版尝试锚点四周的多组位置，每次检查全部已放标签和画布边界；偏离较远时画出连接线。

回归读取实际地图画布上的标签矩形，检查互相遮挡和超出边界。修改前26项中1项失败，修改后26项通过。仍需从实际像素确认图标、连接线与文字是否容易辨认。证据在 `evidence/map_labels_20261006/`。

## 继续试玩的方法

原生 Cua 只有短按键，独立审阅者无法可靠持续移动；这不作为游戏移动失效或玩家迷路的证据。用户已明确授权隔离游戏的系统按键脚本：只对指定应用进程发送 WASD，每次最多3秒，结束自动松开，前台应用变化时提前松开。其他菜单、交互和观察继续使用 Cua。

脚本不改游戏状态，不代替正常寻路、材料准备或活动参与。工具切换、暂停、重建包和观察所用的时间不计入自然游玩容量。普通连续三天、两种完整夏季路线、全局声画与自然210–270分钟仍分别验收，当前不提高十一维评分或替换正式编译包。
