# 澪开衫与袖子收窄（2026-10-22，v26）

用户要求上半身再稍微收窄，主要调整开衫和袖子，同时保留胳膊粗细。本轮只修改五个衣料部件的源关键形。

## 实现

- `BodyRig.fittedCardigan` 将开衫外侧每边收进最多 4 个作者坐标像素。从中央蓝衬衫向侧边、从肩下向腰部平滑增加收窄量；保留领口、肩部连接点和衬衫中部。
- `BodyRig.fittedSleeve` 沿手臂骨段的横向收窄衣料中段，最大 6%，纵向长度不变。肩根、肘部搭接和袖口附近不收窄，保留已认可的接缝。
- 作者端只对 `torso`、`arm_left/right` 和 `lower_sleeve_left/right` 调用上述函数。裸露前臂与手掌不参与，骨段位置、动作参数与运行时的接触求解保持原样。
- 变更写入可编辑 CMO3，再经已安装的 Cubism Editor 5.3.04 官方导出为 Cubism 4.0 / MOC version 3。39 参数、58 ArtMesh、原纹理和 PSD 保留；运行资源对比 v25 只有 `Mio.moc3` 改变。头部及上一轮裙摆比例继续保留。
