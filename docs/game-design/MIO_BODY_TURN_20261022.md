# 澪身体轻微转面（2026-10-22，v22）

按用户要求，让身体随左右转头产生小幅转面。保留 v21 正面形象、稳定眼线与颈部连接，身体不整块侧倾。

## 实现

- 正式源 CMO3/MOC3 增加标准 `ParamBodyAngleX`（-10、0、10 三个关键值）。模型现为 39 参数、58 ArtMesh；原 PNG、PSD 的像素和部件数量不变。
- `BodyRig` 为胸口中线、两侧轮廓和腰部制作不同的水平透视形变。颈部整体平移；肩关节父节点从同一源计算取得位移，手臂、肘部和手腕保持刚性连接。裙子下部、腿和鞋不跟随横移。
- 日常头身跟随比例为 20%，身体范围最多 ±6。Swift 和网页适配层只驱动标准参数，胸肩与腰部形变存在正式模型中；其他 Cubism 播放器可直接使用该参数。
- 头脸只跟随颈根平移，眼形、眼线及脸型不因身体转面而变化。思考姿势按新肩部与下巴位置重算，五组标准 motion3 同步；此前确认的加油前臂内收保持。
- 网页固定左右视线同时固定对应身体转面；跟随视线模式继续动态响应。没有新增独立应用，更新原桌面来信。

## 检查

证据目录：`evidence/mio_body_turn_20261022/`。

- 新测试先加载 v21：9 条失败，能识别缺少身体参数和胸肩透视的旧模型。新版 97 项 Swift 检查中 93 通过、4 项可选网络跳过。
- 18 张真实 Metal 图覆盖五动作的左/中/右视线，以及仅身体转面。正面与 v21 对应固定画面逐像素一致；体态对照为 `body-turn-comparison.png`。
- 实际 Core 顶点验证胸口和外轮廓位移不同，头颈同移，眼脸只平移、足部固定、两手腕连接不脱开；思考接触误差受限。
- 6,514 张动作帧、25 组切换，连接带最低 alpha 254，最大接点误差 0.000137 px，皮肤接缝检查无失败。3,240 个表情组合无网格翻转。
- 原生实窗 40.64 秒持续渲染 2,422 帧，平均 59.60 FPS，五动作、自动模式和左右/正面视线均通过。网页 25 组切换累计 5,388 帧通过，控制台无警告或错误。
- 原桌面来信已重启，渲染计数持续增长且 Clef 已连接；源码、应用和网页的 24 个模型文件摘要一致。网页模型包已重新生成并完成解压摘要核验。交付详情和远端 CI 见 `verification.json`。视觉检查只使用现有显示器，测试静音，不创建虚拟屏幕。

这是一组轻度身体转面，不是大角度侧身动作。肩、胸、腰保留原画的衣服形状，避免为了明显转动再次扭坏头颈或拉长手臂。

## 复现

```bash
python3 art/tools/live2d/export_mio.py --work /tmp/mio-body-turn
bash native/mio-companion/tools/build_app.sh
native/mio-companion/dist/Mio.app/Contents/MacOS/MioCompanion --review-body /tmp/mio-body-turn-views
```

`BodyTurnTests` 可用 `MIO_BODY_FIXTURE` 指向独立旧模型验证失败反例。
