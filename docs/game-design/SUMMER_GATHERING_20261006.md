# 夏祭再用与散场切片

2026-10-06。将首次集市的决定带到后来的实际使用，不重做同一批食物，也不把重约记成原夏祭。

## 可玩的过程

Q05完成后，第16天起庭院出现晚会纸签。实际夏祭时，或当面与澪约好今天树下的一晚后，可以再用合作菜单、代表灯笼或场地方案；也能只逛晚会。没有约定时纸签说明下一入口，不自动开活动。

菜单引用首次确认的配方和试吃批次，今天准备新的一篮。小份/整份的食材是一倍/三倍；自带材料实际扣除，店料明确归莲，每种活动最多一篮三份。两次食品记录分别保存来源、制作人、制备日、领取者和余量，不能清空旧开摊篮来重复领。

盘/纸包放在当前选定桌的真实表面。唯一自有桌沿用空间项目的自动选择；多桌时从场地纸签指定。盘子要求所选观看长椅与取放处在5米内，移动后重新检查。人实际走到桌边才领取一份，桌上减少一份；领取不被说成吃过，无需握物或送到嘴边动作。夏祭的路线给舞圈留开，圈内示范者待走出后再请。

同一盏灯在当前现场重新检查朝向和净空，明确区分festival与reunion；空间共同使用也记录同一活动身份。散场可打包真实余量，满包时桌上份量保留。没有人领取也能收好，不为打包强迫多找一个人。剩食是可存箱的普通食品，吃过只计入本次晚会，不能回写首次集市。

收灯改变当前所在地，不发第二份材料、灯笼、金币或温度。实际灯体回工作桌，作品ID、用途、制作/设计/试挂者与安装历史保留。旧档只有installed、没有history，也先归档已有使用事实，再收回；缺活动身份不推造。

## 验证

首轮回归发现桌面查询会选到P09顶棚、路径数组类型错误和恢复字段的整数差异；有SCRIPT ERROR的运行记录为无效，未计通过。之后24项规则通过，新增旧档收灯、唯一桌、明确重约身份和指定长椅回归。全量结果以`evidence/summer_gathering_20261006/full-final.json`为准。

原生`--gathering-demo`在真实夏祭和明确重约分别准备、实际试走领取、同灯安装、打包、入工作间与SQLite恢复。最终`native-fixed/native-demo.json`为passed=true，共15条截图记录；亲看三份变两份及灯体回桌画面。前章、日期、已有菜单、已保留灯与东侧桌椅是程序夹具，不能算自然发现或整篇时长。

独立审核认为仍缺：按具体对象改变备法与去向；手艺/空间中两种有不同用途的有效安排；工作间生活陈列、日常关系回音和自然主线容量。后续应增加有用途的决定，减少无变化的整轮复验。完整Q15演示、210–270分钟、有效比例和两份整篇75分审核仍未通过，D整批和整个目标保持未完成。
