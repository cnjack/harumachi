# 晴町和纸 UI 素材库（2026-10-03）

当前素材ZIP生成到art/ui-kit/Harumachi-UI-Kit-v1.zip，可用package_ui_kit.py --previews <目录> --evidence <本轮证据>生成；builds只放最新桌面和可选Web。下方2026-10-03旧包大小/路径属于历史，旧包已按保留规则清理。新生成的独立图库版本跟随tools/godot-version.json。


这套库用于统一明年夏祭的按钮、背包、菜单、日历、对话、钓鱼、加载和小游戏。画风沿用暖白和纸、绿灰底色与深青描线；边框以生成的 PNG 为主，金色细线只用作重点和键盘焦点。

## 素材与接入

`game/ui_kit/` 是运行时唯一来源。新增三张透明图集：按钮八种状态、物品格及提示卡八种底图、八个工具图标；合并上一轮24图标和三张背景，加上后续相机图标后共33图标、16控件底图和3背景。当前独立素材包包含原始8张图、49张分开的PNG、52个Godot资源、字体许可、提示词、目录与展示场景。

`tokens.gd` 控制公共颜色、文字层级与间距；`styles.gd` 控制角色和状态；`components.gd` 提供组件。`UITheme`、`UIIcons` 保留原有调用接口，但资源获取已经委托给新库。视图的文字大小仍可按原排版覆盖，不能重新添加私有边框。

按钮具有普通、悬停、按下、禁用状态，主要操作使用绿色，次要操作使用暖白。选择、占用、空格与不可用物品格分开；提示卡用淡绿，警告用珊瑚色。HUD经验、钓鱼进度与加载条复用同一套进度底纹。饭团、拼图、捞金鱼和太鼓小游戏也复用面板样式。地图中的房屋轮廓、地图文字底板和加载灯笼属于绘画内容，由审计显式允许。

## 制作经验

1. 生成时直接要求透明背景、正视、无文字；图标和控件分成规则网格。文字由引擎排版，避免生成文字失真。
2. 输出尺寸可能不同于提示词请求，必须读取实际宽高。按透明像素计算各格边界，目录记录原生像素坐标。
3. 保留原 PNG；只对运行时裁出的区域等比缩放，九宫格角区按最终尺寸匹配。HUD窄胶囊不能套用大弹框角区，否则两端会挤在一起。
4. 薄进度条上下角区必须小于底图高度，留出可拉伸中间区域。按钮各状态保持相同内边距，悬停和按下时文字不会跳动。
5. 素材库要有可运行展示和组合示例。实际界面仍需检查小分辨率、键鼠、禁用与选中状态，单看原图不能验收。
6. 独立包不能依赖 GameState、玩家存档或绝对路径；必须携带字体和许可，并从 ZIP 解压后再运行一次。

## 2026-10-04 相机图标扩展

游戏中的共用库新增相机 SVG、对应 PNG 与 AtlasTexture 编辑器资源，当前为33个图标、16控件和3底图。原始独立 v1 ZIP 保持其历史32图标版本。新增文件在 `game/ui_kit/assets/controls/camera.svg`、`png/icon_camera.png` 和 `resources/icon_camera.tres`；`prepare_ui_kit.py` 保留此扩展，PNG 用 Godot 的 `art/tools/export_control_symbols.gd` 输出，避免两套渲染像素不一致。

方向、奔跑、鼠标与缩放采用 `ControlGlyph` 绘制的矢量符号；按钮仍使用共用语义皮肤。六鱼动画图集作为物品美术放在 `game/assets/ui/fish/`，由 `FishArt` 提供原生透明区域，并经 `UITheme.icon_texture` 共用。来源、提示词和本轮验证见 [生活更新](LIVING_TOWN_20261004.md)。

共用素材库新增独立 `animations.json` 和 `resources/title_cat.tres`，原图标、控件与底图目录保持其数量。标题橘猫采用八帧走路、四帧待机的透明动漫图集，左右走动并在端点暂停；原图像素和透明通道保留，仅用 AtlasTexture 区域与留白对齐。菜单没有 3D 视口或骨架，忽略输入；具体来源与验证见 [猫的模型与动画](CAT_MOTION_20261004.md)。

## 2026-10-05 垂尾卧猫组件

`UIKitComponents.resting_cat(width,anchor_fraction)` 在面板上边缘放置一只小卧猫。身体为固定 Sprite2D，八帧尾巴垂到边缘下方独立摆动，原图像素和 alpha 保持不变。组件忽略输入、暂停时继续动画；已用于背包、日历、设置。标题猫另有走路、趴下和起身状态。资源、使用边界与实机验证见 [垂尾猫](CAT_UI_REST_20261005.md)。
