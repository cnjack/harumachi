# 空走路膝盖内扣修复（2026-10-18）

用户本次明确指出“空走路的时候膝盖内弯，跑步和站立没问题”。这条新反馈替代原49项中空 walk 的通过结论；原始点评及v97页面保留，空的 run/idle 按本次明确认可保护。

修复只在 `NaturalLocomotionPose` 的 Sora + walk 分支重新确定膝盖向前弯曲的平面：以当帧原踝位做定骨长双骨求解，保留脚朝向、骨盆和上身动作，继续使用原接地安全支持及过渡混合。没有重烘模型或改全局 IK；七模型、脚面支持和动画控制器均未变。

## 原因与负控

修前正背面可见两侧膝盖向中线收；同帧最终骨包确认该外形对应真实膝轴。原 walk 的膝弯曲平面已向内，接地 IK 沿旧平面抬踝，又放大了内扣。修前原生街面相位0.5625右膝相对同侧髋踝连线的有向侧偏为 −107.084毫米；33相位 headless 地面回归最差 −121.87毫米。两环境高度不同，数值分开记录。

新增检查使用有向侧偏，负数为向内；阈值为不低于 −10毫米，并要求33个相位均为最后 modifier 的新鲜回执。先跑旧生产代码，89项中仅该新增项失败；修后89项全部通过，最小侧偏 +6.49毫米。原骨长、完整鞋底和循环接缝检查保留；其余85项连明细相同。此阈值只用于空 walk，不强加给用户认可的跑步姿态。
