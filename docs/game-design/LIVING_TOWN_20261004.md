# 钓鱼、住宅街与生活演出（2026-10-04）

## 本轮变化

拆箱小游戏的入口、脚本和专用游戏素材已经移除，客厅的纸箱保留为搬家的装饰。旧存档里的成绩与已经获得的金币保留，“小游戏全三星”成就也改为四款可玩的游戏；当前小游戏列表和星级总数只统计捏饭团、地图拼图、捞金鱼和祭典太鼓。

钓鱼仍使用现有四个真实水岸交互点，收线改为鱼影追踪：按住 E、空格或左键使控制区向右移动，松开向左移动。鱼在绿色区间里时才收回进度，丢失鱼影会损失进度；一直按住会张力失控。鲫鱼平游，鲤鱼和鳗鱼下潜，香鱼、虹鳟和湖鲈急转；更难的鱼有更窄的区间、更快的移动和更慢的收线。

| 钓点 | 鱼群 | 时间条件 |
| --- | --- | --- |
| 晴川浅滩 | 鲫鱼、香鱼 | 香鱼在 07:00–18:00 |
| 柳影河湾 | 香鱼、虹鳟、鳗鱼 | 虹鳟在 06:00–11:00 / 16:00–24:00；鳗鱼在 06:00–08:00 / 18:00–24:00 |
| 镜波湖栈桥 | 鲤鱼、湖鲈 | 06:00–24:00 |
| 芦苇东岸 | 鲫鱼、湖鲈、鳗鱼 | 鳗鱼为早晚鱼 |

每竿仍耗一份鱼饵和 12 分钟。满背包不能扣饵，取消或错过鱼不生成鱼获，同一竿不能重复领奖。雨天的虹鳟和鳗鱼权重继续增加。鱼获仍可出售、料理、进入图鉴和保存到 SQLite。

持竿时在空的现有骨架上叠加手臂姿势，鱼线、浮漂与波纹在场景里移动；成功时鱼从水里跃到玩家身边，角色庆祝，叠加动漫放射线和花瓣。六种鱼改用一张原生透明的平涂图集，提示词保存在 `art/manifests/prompts/living_town/fish_atlas.txt`。使用内置 imagegen，保留生成 alpha，通过 AtlasTexture 取区域，没有按底色抠图。料理完成和小游戏结果也加入了短演出。

## 睡前手账

床的原有选项继续使用：傍晚后可睡到明天，白天可午睡或只保存。跨日睡眠与午夜回家时，会先显示今天的收入、支出、收获、鱼获、出售品、街坊、赠礼和 XP。午睡不做日结。按回车、空格、Esc 或点击晚安关闭。

总结从真实 ledger、daily 和物品数量取快照；先保存 `flags.last_day_summary`，再清空日计数、处理第二天并自动存档。仍是 v4 存档，旧存档无需迁移。失败存档的提示与上一份有效快照继续由现有每日存档逻辑处理。

## 村子与画面

原住宅支巷从 z=32 接到 z=85.2，增加六栋房屋、门前小路、信箱、花盆、灌木、自行车、矮墙和路灯。原巷尾围墙和链桩移除，玩家可以一路走到街尾。住宅位于支巷以南，商业区仍在石板主街；地图同步显示新增街道与房屋。新增住宅提供室外街景，未开放六栋房屋的室内或新增住户剧情。

远景的南侧屋顶卡片移到 z=128，南侧实体树移到新边界外，避免横穿住宅街。水面增加随白天、黄昏、夜晚切换的天空反射、浅水纹路和暖色高光；降低室外雾与补光，延长阴影距离。保持平涂、硬边和偏蓝紫的阴影。

公交有减速停车、开门、玩家下车与驶离的开场。当前车身是程序组装的奶油白与青绿乡间公交，门和轮胎是独立部件，没有调用付费模型生成。

动物调研及已接入的局部动作见 [动物动画调研](ANIMAL_ANIMATION_20261004.md)。完整猫行走和跳跃仍需要站姿四足模型与专用动画，不能把局部呼吸、转头当成完整动画库。

## 拍照与图标

F8 进入拍照模式，WASD 平移、Q/E 升降，右键转动，滚轮改变焦距，Shift 加速。可以隐藏玩家，F6 隐藏操作条，F12 保存 3840×2160 的无界面 PNG。照片放在系统“图片/Harumachi”，保存后按钮显示完成标记与路径提示。Esc 恢复镜头、姓名、时间和输入状态。不会写入玩家位置或改变存档。

移动提示改为方向、奔跑、鼠标和缩放图标；地图、背包、委托、日历、图鉴、拍照和菜单按钮只保留图标与按键。说明放在悬停提示里。新增相机 SVG、PNG 与编辑器资源都在共用 `game/ui_kit/` 里。

## 验证方式

新 LIVING 专项覆盖旧拆箱存档、通路和地面碰撞、公交门轮、麻雀独立翼片、猫的接触、不同水域鱼群、持续按住失败、所有水域可成功、透明鱼图、日结快照、SQLite 重读、拍照进入退出和图标控制。

旧版首次 22 项失败 20 项；修复后全量 595 项通过。随后补充旧拆箱星级兼容回归，最终结果、导出包及实际应用检查写在本目录 PLAN 与 `evidence/living_town_20261004/`。原始失败日志保留，测试涉及 SQLite 不可写场景时故意触发的数据库错误与脚本解析错误分开看。

带窗口的 `--living-demo` 使用真实 E、F8、F12、Esc 输入：公交到站，完整步行住宅街，动物近景连续帧，四个钓点的抛竿/收线/鱼获，4K 图片，床的实际睡眠选项，日结和第二天存档。导出应用从标题界面以 `--newgame --living-demo` 进入，不给导出应用传场景路径。
