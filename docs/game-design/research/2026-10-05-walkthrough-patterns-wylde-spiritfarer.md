# 从具体攻略看生活剧情：Wylde Flowers 与 Spiritfarer

2026-10-05。抽样核查两段《Wylde Flowers》和三段《Spiritfarer》的任务流程，研究“每天一段生活剧情”怎样由玩家动作和人物回应组成。此轮没有运行两款游戏或晴町，没有改源码与 PLAN；游戏中的具体流程与晴町的设计建议分开写。下文包含原游戏任务发展剧透，但不复制角色对白、人物设定、魔法或离别机制。

最可迁移的共同点是：让一件普通需求引出行动，行动留下具体东西，再由人物使用、回送或邀约接住。并不是多写一段好感对白。晴町先把入场的饭、实际回送、还饭盒和分食做成可玩的动作，比立即增加七段新任务更接近这条结构。

## 资料与版本边界

- 攻略用于核查触发、步骤和后续；官方更新页用于识别规则变化，不能用官网宣传语替代攻略。
- 部分 Fandom 页面直接打开被限制；本轮读取了网页搜索返回的页面内容，并与能完整打开的攻略及官方更新交叉核对。来源没有说明的错过窗口、延期、背包或异常恢复均标“未证实”，不假定所有任务永不失败。
- 《Wylde Flowers》早期攻略可追溯到 2022 年，但官方后来改变了关系、季节与错过内容的恢复。特别是拒绝后是否可以再发展关系，不能只看旧版攻略。
- 《Spiritfarer》的 [官方页面](https://thunderlotusgames.com/games/spiritfarer/) 说明 Farewell Edition 包含后续内容。攻略与 Wiki 的部分菜单和前置列表不一致，下面保留一致流程，不把某一份旧清单当当前全版本真相。

## Wylde Flowers：劳动最后变成一碗汤

### W1．The Fungus Among Us

| 检查项 | 核查结果 |
| --- | --- |
| 触发与前置 | 开场种下土豆后，奶奶要做晚饭，让 Tara 去找蘑菇 |
| 玩家动作 | 沿山路找两朵蘑菇，带回家交给奶奶 |
| 选择与后续 | 核查到的是线性料理教学；具体任务页与任务表均记交付后等到次日，收到两份蘑菇汤，没有证据显示这里有故事分支 |
| 材料不足/错过 | 具体任务页有尚未找到蘑菇、继续寻找的回应；未说明很晚交付或跨季补做方式，不能把它列为已验证的永久可延期事件 |
| 人物与场景变化 | 奶奶有她正在做的晚饭，玩家走过山路、回到家，劳动由料理接住；来源不足以证明逐帧共同用餐演出 |

材料、交付后次日领取与未找到时的回应见 [具体任务页](https://wylde-flowers.fandom.com/wiki/The_Fungus_Among_Us)，跨日步骤也见 [任务表](https://wylde-flowers.fandom.com/wiki/To-Do_Quests)。

**来源分歧与修正：**[Nintendo Smash 的 2022 年攻略](https://nintendosmash.com/wylde-flowers-the-fungus-among-us-quest-walkthrough/) 写交付后等到夜晚；具体任务页写次日收汤，结尾对话也明确邀请明天再来，任务表同样要求等待到下一天。因此本报告采用跨日领取，不再把当天晚间当统一事实。本轮没有实机证据证明差异来自版本，不能据此解释为某次更新修改了时点。

**对晴町的建议：**第一天让“安顿”有眼前的一餐。食物有真实来源，拿到食材、做成/领取食物与选择去向都入记录。两份食物可以设计成自己吃、带一份出去或明天再吃，这是晴町的新增选择，不是声称原任务已有这些分支。

**不适用的部分：**不要让第一顿饭必须先完成种植与长采集路线，也不要只在结束时加两份道具便称“生活化”。晴町的重点是实际饭桌、角色停留、声音与吃完后的变化；如果只看一张奖励卡，关系和感官维度仍未闭合。

### W2．Dinner For Two, Please，以 Amira 的事件为例

| 检查项 | 核查结果 |
| --- | --- |
| 触发与前置 | 满五心后有赴约邀请；接受后收到 Sophia 的信，再找她安排晚饭 |
| 玩家动作 | 交两朵蘑菇和一条金枪鱼，按约定到次晚晚餐；事件页给 Amira 的时间为 20 点 |
| 选择与后续 | 到晚餐时仍可接受发展关系或表示想做朋友；事件页记载后者回到四心/好友。交食材并不代替最终关系选择 |
| 材料不足/错过 | 材料交齐才进入次晚安排。此次未取得可靠的“迟到任意一晚仍可重约”规则；不能把一般恋爱恢复当成具体迟到恢复 |
| 人物与场景变化 | 信件、餐厅准备、次晚相聚分属不同状态；第三人也参与安排，关系进展有独立场景 |

食材与次晚安排见 [具体任务页](https://wylde-flowers.fandom.com/wiki/Dinner_For_Two%2C_Please)，触发与饭桌回答见 [Amira 事件页](https://wylde-flowers.fandom.com/wiki/Amira_Syed/Events)。

**版本差异：**官方 1.0.5 更新将拒绝/分手描述为转成永久朋友；1.3 又加入花束重续关系。新旧攻略可以同时对自己当时版本成立，因此不能由旧页面推断当前永久错失。见 [官方更新记录的 1.0.5 与 1.3 段](https://wyldeflowersgame.com/changes.html)。

**对晴町的建议：**不引入恋爱系统，借用“邀请→准备→约时间→实际相聚→当面选择→以后回应”的结构。春的饭盒、莲的试吃、小葵来年的联系都适合；收下食物不代表接受长期供货，聊得熟也不代表答应明年一定留乡。

**不适用的部分：**不照搬五心才能吃饭、拒绝即降心或只能同时维持一条关系。普通邻里生活应更早发生，允许自己吃、约改天或保持朋友；延期入口和晚到文本必须由晴町独立设计和验证。

## Spiritfarer：学习、照料与物件能接成一条线

### S1．I Get Cranky When I’m Hungry

| 检查项 | 核查结果 |
| --- | --- |
| 触发与前置 | 接在初期船与客舍任务之后，Gwen 的吃饭需求引出厨房 |
| 玩家动作 | 去采集发光水母材料、造厨房；领取她给的玉米，入炉等熟，再交食物 |
| 选择与后续 | 任务目标写的是给她食物，攻略示范爆米花；不是“只能做这一菜”的完整分支证明。厨房留下来，下一步衔接种植 |
| 材料不足/错过 | 厨房需建筑材料；烹饪中取消会返还未熟原料，完成有炉子/提示音反馈，放置太久会烧坏。不能据此声称做菜无失败 |
| 人物与场景变化 | 需求变成永久厨房、实际做成食物与人物心情；她还提供首次教学材料 |

任务步骤与玉米来源见 [任务页](https://spiritfarer.fandom.com/wiki/I_Get_Cranky_When_I%27m_Hungry)；示范流程见 [Gwen 攻略的对应段](https://guidestrats.com/spiritfarer-gwen-guide/#i-get-cranky-when-im-hungry)；取消、提醒与烧坏规则见 [厨房操作页](https://spiritfarer.fandom.com/wiki/Kitchen)。

**对晴町的建议：**让教学来自眼前的人和需要。现有厨房已存在，无需再造建筑：先给一份有出处的可做材料，完成时有短动作/音效，再让玩家决定食物给谁。人物不能只在结尾说“真厉害”；可以教一种做法，之后用这件能力帮助自己过一天。

**不适用的部分：**不照搬厨房前多重采集和建造门槛、食物烧坏惩罚。晴町的低压力定位可以保留成品，挑战由菜式、安排和技巧承担；同样不能用一次互动冻结时间把所有反馈塞成弹窗。

### S2．Back to the Past → More Than Meets the Eye

| 检查项 | 核查结果 |
| --- | --- |
| 触发与前置 | Gwen 已有织机教学，玩家需要二段跳；她提出回家族旧宅，并提供位置与钥匙 |
| 玩家动作 | 在旧宅沿房间路线登上阳台，找到音乐盒与织机升级资料，交回物件；下一请求才用材料升级织机 |
| 选择与后续 | 核查到的是线性探索与交物，未见改变 Gwen 身世的选择；私人旧物与玩家能力升级并行 |
| 材料不足/错过 | 升级材料不够可以继续收集再建；没有材料不能提前获得升级。未核实所有版本的触发等待长度/中断状态 |
| 人物与场景变化 | 原本地图上的目的地成为可探索屋内，私人回忆有物件可拿，随后织机真正能把线织成布 |

二段跳与任务前后关系见 [任务页](https://spiritfarer.fandom.com/wiki/Back_to_the_Past)；旧宅路线、钥匙、音乐盒和后续机器变化见 [Gwen 逐步攻略](https://guidestrats.com/spiritfarer-gwen-guide/#back-to-the-past)。

**对晴町的建议：**旧物不只解锁一段说明文字。奶奶的碗柜、田中的工具、莲的纸签可以有“找到→弄明白→现在用上→留下一处变化”的链条。不是每件旧物都给技能；有些只让空学会使用房子里的东西，或让邻居找回一种习惯。

**不适用的部分：**首周不需要平台跳跃谜题或新大宅。将一条跨多日的回忆线硬压进每天一段，会使情感披露密集；旧物有后续也不等于每晚都要揭一个重故事。

### S3．Family Style → Sous-Chef Extraordinaire → Au pied de grenouille

| 检查项 | 核查结果 |
| --- | --- |
| 触发与前置 | Atul 的人物请求推进到聚餐；Wiki 列前项为 Fishing Trip，其他攻略还涉及工作室升级，完整触发组合此次未统一 |
| 玩家动作 | 邀三位乘客，记下各自要的菜；未学的对应配方可获得。把料理交给 Atul，准备完成才去 Hummingberg 聚餐 |
| 选择与后续 | 宾客名单决定准备内容；实际默认是开始该请求后先交谈的三人，而不是独立确认名单。聚餐结束后 Atul 离开，属于原作离别主题 |
| 材料不足/错过 | 按已邀请者的菜单补材料；Wiki 记载已离船的受邀者仍要求其菜，并提示不足三位乘客可能出问题。未核实这些问题在当前所有平台是否仍存在 |
| 人物与场景变化 | 单人做菜转成多人共同场景，换到岸上相聚；结束会改变人物在场状态，不是普通重复活动 |

名单与人数风险见 [Family Style 任务页](https://spiritfarer.fandom.com/wiki/Family_Style)；按邀请者做菜及补给配方见 [料理请求页](https://spiritfarer.fandom.com/wiki/Sous-Chef_Extraordinaire)；准备、地点与后续见 [Atul 流程攻略](https://www.neoseeker.com/spiritfarer/characters/Atul)。受邀者先离船仍需料理的记录见 [Atul 的 Game Notes](https://spiritfarer.fandom.com/wiki/Atul)。

**资料冲突：**[Guide Strats 的 Atul 菜单](https://guidestrats.com/spiritfarer-atul-guide/#sous-chef-extraordinaire) 与任务 Wiki 给部分乘客不同菜名。这可能有整理错误或其他差异，本轮没有足够证据归因于版本。本文不采用具体菜单清单，不将普通最喜欢食物直接当宴席所需料理；晴町要从实际事件订单读菜单。

**对晴町的建议：**邻居的口味和闲暇应真正影响“要做什么、谁能来、何时吃”。玩家确认邀请名单后生成小菜单，准备不足能缩小份量/借一点/改天；场景之后还餐具、分剩菜、收凳子，形成跨日后续。Q16 已有试吃人的意见和订单，可以继续用这条线，避免新增同样的交菜任务。

**不适用的部分：**不用先三人交谈就自动邀人，不让缺席者仍占必要菜单，也不把一顿普通饭接成突然永久离开。晴町此阶段希望更生活化，人物告别若需要应由自己的四季故事建立，不能套用原作的情绪装置。

## 用十一维审核可迁移结构

以下是从上述流程得到的设计推论，不是两款游戏已经通过晴町评分，也不是晴町现有实现。

| 方向 | 对晴町的具体审核问题 |
| --- | --- |
| 核心循环 | 食物除了出售，是否真能自己吃、分享、保存或合作？去向会不会引出下一次生活安排？ |
| 即时反馈 | 采集/料理/交付后，实际物件、声音与状态是否同步；对方用上或回送时是否查真实记录？ |
| 挑战与心流 | 教一种动作后有没有自己试与轻松停留？等菜熟能否去做别的小事，缺料有没有可理解的继续入口？ |
| 成长与掌控 | 第一次学会的事以后仍能用；不是剧情结束能力和场景又失效 |
| 自主与选择 | 收食物、准备材料、到场与答应下次分别记录；邀请名单需确认，延期不代替接受 |
| 叙事与沉浸 | 今天的台词是否对应今天发生的事；私人回忆有实际物件，当前生活能接住它 |
| 社交与关系 | 谁教过玩家，谁回送过东西，谁有自己的忙碌和拒绝，而非全部赞美玩家 |
| 审美与感官 | 饭桌、蒸汽、拆纸袋、归还时的镜头与声音能否读懂；攻略有此步骤不等于本作已经有动画 |
| 惊喜与创新 | 回到同个地方能发现上次选择留下的变化；不用每天硬塞新系统或不可预知奖励 |
| 情感与意义 | 能记住自己与谁做过一件事；不依赖每天回忆去世者或重大告白维持情绪 |
| 可及性与摩擦 | NPC 打烊、缺材料、迟到、满包、读档能继续；恢复路径要在此作实际验证，不能从别作概括推定 |

## 首周样本可以借用的最小结构

建议事件卡写成六步，先用于“第一顿饭”与“春的回送”，不立刻扩成整季任务数量：

1. **邀请有眼前原因。** 有饭待做、有人今天腌了菜、店里余下两片面包，不先讲宏大目标。
2. **原料和物品来源清楚。** 领到多少、是谁的、可留给自己还是需归还，玩家知道。
3. **玩家做一个可见动作或有效选择。** 吃/打包/分享、收/晚点拿、问做法/只是聊天。不是所有选项都进同一步。
4. **实际提交再记录完成。** 食物未到账、背包满、NPC 没出现都不能先写“已吃饭/已赠送/共同参加”。
5. **世界留一处变化。** 饭盒、纸签、洗好的碗或一份留到明天的食物，与真实状态对应。
6. **下一次回来只给短回应。** 归还、回送、问味道、邻居说忙或换约；没参与就用自然的未参与版本。

其中 W1 是“劳动→晚饭”，W2 是“准备不等于承诺”，S1 是“需求→学会一种手艺”，S2 是“旧物→现在用上”，S3 是“不同的人→不同准备→共同场景”。它们可拆成生活日的候选，但不要求玩家每天全部完成，也不要求每天添加新的系统。

当前修复解决的是若干选择与事实问题。吃饭、回送、归还等实际动作和可见跨日回应仍须制作与试玩；本报告不将攻略研究或已有回归成功写成晴町已经好玩。继续门槛仍使用 [FUN_REVIEW](../FUN_REVIEW.md)，具体首周安排仍由 [SUMMER_DAILY_STORY_PLAN](../SUMMER_DAILY_STORY_PLAN.md) 承接，本轮没有改动它们。
