# 首次集市接入与社区工作间

2026-10-06。本轮继续完整夏季约四小时目标，未将首个周末或单灯切片当作整篇完成。实施范围对应B的主线接入与C的首个可操作灰盒。

## 新档的首次集市

Q01公告栏介绍一小篮合作。送篮、种植箱、标牌成为可选委托，不自动接受、不自动完成、不发对应报酬。新玩家从面包店合作纸签选择自己试做或负责招待，准备真实试吃小份，听两位意见，确定份量与盛法，按实际桌椅和碰撞试走。方案成立后Q05可接受，不以种田为前置。

澪会听玩家汇报方案，桌椅不重复发。J直接接受也能继续找澪汇报；准备完成的浮标指澪，邀请阶段指未邀请的邻居。主线、生活小事、合作与每日请求互相替换追踪，J可暂停或恢复合作。手账保留菜单、批次、材料来源、制作人、试吃者、份量、盛法、实际递出与剩食。

最终食物篮等实际开摊后才准备。开摊不凭空种出番茄；新路线的Q05必须真实递给至少一位街坊，再完成三次聊天。打包、收纸签和递餐分别反馈实际结果，不能把打包说成递出了新一份。Q05仍是章节总结。

旧档缺少mainline_mode时明确保留legacy规则。旧的活跃或完成Q05不倒退，不补造合作成果。旧三清单的完整回归作为legacy分支保留；新分支另测实际J与角色入口。

## 工作间、旧账本与代表灯笼

社区中心门口进入独立12×9米室内，坐标(110,0,400)。有实际地板、门洞、工作桌、储物架、活动标牌台和试挂架。离开与室内读档支持第三种房间，不把工作间当作面包店或卧室。此处仍是灰盒；中央桌已换成Hyper3D工作台W13，原始GLB保留；统一缩放1.5到0.78米，保留24个榫接、横撑和桌腿部件。倾角0°，实际桌面0.78米，经过游戏截图和实体支撑检查。其余室内陈列仍是灰盒。

Q11的账本在储物架翻看。用具页或场地页能引出账本和春的后续，不要求把全部页面读完。其他页可回来看，页码按真实查看记录。旧档仍可使用原账本入口。

Q11交谈完成后，在工作台选择用途（树下碰头或入口指路）、纸面（榉叶或水纹）与分工。手作通过A/D或按钮转动，空格/扣上固定三个真实可见接头；错误不会毁材料。首个接头消耗一份和纸和竹篾一次，之前材料受保护。取消留下角度和接头，SQLite恢复半成品。轻操作由街坊准备灯体，玩家仍决定用途、纸面和试挂；制作人、设计者、试用者分别记。

试挂会改变实际灯体的高度、纸面朝向与灯光。净空用当前实体碰撞的9个头部球采样，纸面用观察点法线与遮挡射线检查。低位挡头、背面看不到均不能保留；正确方案可直接保留，不要求故意返工。这是局部试挂检查，尚不是居民完整试走或整段来路可达测试。

夏祭现场使用同一个work_id。玩家主动带过去才出现，不靠换日凭空发一盏。入口的来路与工作间不同，旧朝向需要现场再检查。安装后改高度或朝向会撤销旧成功记录；未安装的现场预览取消后可以回工作间恢复。同一件作品只有一份材料身份，没有另发五盏库存。
