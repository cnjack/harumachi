## 支出边界

官方Gen-2.5接口文档列出基础生成0.5点。使用现有登录的`hyper3d` CLI，档位明确为Gen-2.5-High，不启用额外付费项。120个提交槽共60点，每件预留A/B两个候选，第二槽根据第一槽的实际缺陷修正参考或提示。候选质量和是否复用由逐件视觉评审决定，不能因已付费就接入。

`art/tools/hyper3d_budget_batch.py`在提交前后读取账户、记录实际余额，并核对同一账户、最低余额150、槽位唯一性。提交意图先落盘；响应不明时保持锁定，不重提。轮询和下载只使用已存任务ID。失败、退款、价格变化或其他同时发生的消费必须对账后再分配剩余槽位；不得为了凑次数越过60点。实际最终扣点必须用服务余额证明，不能仅以提交次数推算。

## 每件模型的标准

1. **轮廓和用途**：正常游戏距离以及256像素缩略图仍能辨认；相似单体至少在轮廓、构造或植物习性上存在真实差别，换颜色和旋转不算新模型。没有模型外的平台、杂物或莫名组合。
2. **画风**：按`ART_STYLE.md`使用干净平涂、克制线条和硬边阴影；材质粗糙度接近1、金属度0，不依靠强镜面或照片噪声表现。树叶有分组和空气间隙，不能是密不透风的球或三角碎片。与旁边已验资产同框检查，日光、黄昏、夜灯和雨天均需保持一致。
3. **实际结构**：四面可用，去材质的灰模仍有该有的孔洞、把手、檐口、筐缝、工具间隙及花叶结构。不能用贴图画出窗洞或用平面冒充完整树体。关键开口和承重结构各留近景证据。
4. **尺寸与支撑**：统一米制、Y向上、底部原点、正面朝向固定。重做模型以现有实测尺寸和场景净空为约束，保持均匀缩放；确需尺寸调整时同步摆放和碰撞。硬物底面误差不超过1厘米、主体倾斜不超过1度；自然弯曲树干不使用硬物倾角标准。桌上小物必须由真实渲染桌面支撑，作物根部贴种植土面。
5. **性能和复用**：小物约4–8千三角面、中型道具8–16千、小建筑和树不超过2万，逐件预算见清单。常规贴图1024，近景复杂物最多2048；保留必要透明叶片，不携带无用PBR图。新树的可见面、阴影和碰撞分别预算，不能把完整叶冠做成移动镜头碰撞。来源、任务、参考图、导出参数、摘要、评审和使用位置必须可查。

五项视觉维度分别记录0–5分：辨识、画风、结构、四面完成度、用途匹配。每项至少4分，且没有上述结构或摆放硬失败，方可接入；分数必须附具体观察和截图路径，不用统计量替代人工看图。

## 分批流程

先做独轮车、雨水桶、蔬菜筐、石灯、小祠堂、工具架六件，验证参考→Hyper3D→四面/灰模→减面→游戏导出的完整链路，再展开植物、作物和生活单体。参考图逐件使用内置imagegen，保存原图与提示词；任何反馈修改后再提交第二候选。Hyper3D原始文件和未选候选留在忽略的raw目录，正式GLB和来源清单进入Git LFS。

## 制作与专项结果

120个候选全部下载并记录原始摘要。服务余额已实际结算为150点、冻结0点，实际消费60点，后续生成入口禁止继续提交。60件来源与最终减面成品已逐件查看四面、斜角及灰模；当前共264件游戏GLB。60件均已完成晴天、黄昏、夜间和雨天原生复拍，另有八种作物三种早期阶段、六种树根和关键结构近景。203项专项、1800项独占全量与解压桌面包200项完整夏季演示均通过，退出码0。

实际检查与修正：

- 完整底面逐顶点检查，避免小物只在中心有支撑却悬边。壶、茶壶与育苗盘根据实际网格筛选位置，果盘由桌布低面移到完整桌面。育苗盘同时避开P08内嵌花盆与居民两处茶托位置。旧位置4项失败，修复后全过。
- 作物旧代码按木框最高点估算土面，原生复拍仍能看到悬浮。回归改为真实土垄三角面，在旧摆放抓到16项生长/成熟失败；种子、幼苗、生长及成熟均随实际土面落位。胡萝卜和洋葱仅在生长/成熟时按比例埋土；库存、陈列与单体保持完整。茄子收获后仍再生。
- 四种候选树缺少夏季叶冠，保留生成主干并补上分种树冠。树根近景发现减面会撕裂Raw模型的UV接缝，先焊接再减面，并去除0.03%至7.63%面积的分离枝片。旧四件闭合回归全部失败，最终主干均为一个闭合连通体，透明叶卡单独测量，不用叶卡开放边冒充树皮问题。新树还检查真实树干与墙体净空及周边胶囊通行。
- 三件坏编织篮、萝卜筐和纸网托盘在Blender中重建规则结构，保留可用内容物；针线篮布料和紫色果体的颜色分区误切已修复。手套背面的绿色点经896像素近图确认为指尖，完整白色掌背保留。
- 导出器旧默认值覆盖了新模型粗糙度，仅本轮配方明确粗糙度1、镜面0；原有模型配方不变。桌面支撑逐个测量同名实例，并接入既有实际支撑协议；纸网托放到金鱼池旁复用木凳上，面具架移到摊位前。完整PROPS46项、PLACEMENT12项已通过。
- 264件承重面测量与几何/材质审计完成，既有五项合同通过；素材室登记60件中文名称、来源、参考、预算及用途。所有原始A/B文件和未选候选保留在忽略的raw目录。

本轮实际消费Hyper3D60点，余额210→150、冻结0；120个候选中逐件选择并完成60件模型，24件替换、36件新增，游戏共264件GLB。四面/灰模、60件四天气实拍、24组同机位对比、203项专项、1800项独占全量及解压应用200项完整夏季演示均通过，默认104个存档和照片文件摘要不变。唯一桌面ZIP已更新，Web保持原版本。

全量首次抓到工作台改变宽深与台面高度后阻断麦茶E射线，产生3项失败。保留完整陶盆和铲头，重建准确木架与下层育苗盘，恢复原实测操作空间；旁边桶移出工作台脚印。喝茶53项、居民晨间32项、环境35项、PROPS46项及模型专项203项复测全过；实机两种托盘方案分别落在(15.8,1.03,15.45)/(15.8,1.03,15.75)，育苗盘与居民动作不互相侵入。没有放宽原有交互或工作面容差。

最适合继续重复使用的是空筐/木箱凳、容器和茶具、育苗盘与园艺小物：有独立网格、完整四面和统一米制，木箱凳已在两处不同用途实际复用。六种树与六种盆栽用于打散重复剪影；树要连同透明叶材质和简单根部碰撞使用。节日面具、纸网和竹灯用途更集中，适合在相应摊位组合，纸网须由干燥桌面或凳面承托。八种作物要沿用真实土面与阶段逻辑，不能把游戏中埋土后的状态当作通用模型底部。
