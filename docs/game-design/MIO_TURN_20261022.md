# 澪左右转面与加油前臂修复（2026-10-22，v19）

用户要求左右看时面向左右。此前视线直接增加头部侧倾，而源模型最大水平转角只有约 9.7°，因此主要看起来像左右歪头。本轮将实际转面做进可编辑 CMO3 和官方 MOC3，并移除视线到侧倾的映射。

## 源模型和播放

- `FaceRig.turn` 的三乘三关键形采用约 ±28.6° 水平投影：鼻尖、下巴相对脸颊移动，远侧眼睛收窄，前后头发按不同深度移动。有限斜率曲面避免边缘网格翻转，俯仰沿用原范围。
- `ParamAngleX` 控制转面；`ParamAngleZ` 保留动作本身的轻微歪头，水平视线不再额外改变它。桌面源动作及 motion3 播放使用同一规则。
- Pixi 0.4.0 会在动作之后叠加鼠标 X×Y 侧倾和呼吸侧倾。可选网页适配层记录动作角度，并在 Core 更新前恢复，保留动作里的思考倾斜。依据为 [Cubism4InternalModel 官方源码](https://raw.githubusercontent.com/guansss/pixi-live2d-display/v0.4.0/src/cubism4/Cubism4InternalModel.ts)。标准模型本身已含转面关键形，第三方播放器仍可自行添加视线效果。
- 按上一张箭头图的内收方向调整加油：肘部略向外，前臂向脸侧倾斜，保留上一轮手背朝外的拳头。三段保持相位中，手腕均位于肘部内侧至少 12 个源坐标像素。
- 思考动作重新烘焙，使食指接触目标与新转面下巴一致。

没有重画纹理。原眼睛、脸型、头部 0.736 比例和认可的衣袖素材保持不变；默认正面 Metal 截图与 v18.2 **逐像素相同**。运行包仅 MOC3、加油 motion3、思考 motion3 变化，三张图集均字节一致。来源与摘要见 `art/manifests/mio_turn_20261022.json`。
