# 人物源衣物、跑步手臂与平地接触（2026-10-18）

本轮按用户要求，先在关闭游戏修正器的源模型上修复，再检查实际游戏。本轮普通日常动作的源修复与技术验收已完成；自然度保留人工复评。测试使用现有实体 screen 0、Dummy 音频、不抢焦点及独立存档，没有创建虚拟显示器。桌面 ZIP 和 Web 不随本轮更新。

## 衣物：既检查穿入，也检查衣形

澪的源裙面使用 96 个独立接触修形和一个最大 3.790 毫米的接缝修形。全量体表顶点与完整三角面见证点保留，身体顶点的新增 POSITION/NORMAL 均为零。

和子原先将静止空间 Z 推移直接蒙皮，大腿高屈曲时会把避让变成向上的位移，产生硬卷边。候选 v6 虽通过穿入数值门槛，实际侧面仍不自然，未作为最终验收。纯腰部权重方案又失去必要跟随，完整表面检查失败，也未采用。

当前方案保持原蒙皮和源动画，在每个源姿态固定模型空间 X/Y，只沿身体前后方向求衣物避让，再用实际蒙皮矩阵的逆矩阵写回普通 XYZ 形态键。walk/run 各 128 个基础相位，run 另加 6 个相位，合计 262 个源接触形态键。额外小场只补独立黄色衣片中没有 Local 支持的边角，范围不延伸到身体。作者侧接触余量为 8 毫米，位移硬上限仍为 12 厘米；这些是修形位移，不是衣服与皮肤的空隙。

独立加密检查曾在 run 0.48046875、0.94921875 检出 13.6/34.4 毫米穿入，因此添加相位及邻近键，并将这两个反例加入原生源回归。验收仍用原 5 毫米穿入、0.35 法向筛选和完整源衣面，不删除失败面，也不缩小身体覆盖。最终每动作 512 相位与原生报告通过，见 `kazuko-world-v13-dense-surfaces.json`。

## 跑步手臂与接地

七人 run 的 36 条 Arm/ForeArm/Hand/手指旋转曲线写入 GLB，降低手位、收小摆幅、保留肘平面，手腕轻微内收、手指松握。`NaturalLocomotionPose` 读取真实源元数据，跳过重复的手臂与手型修改；实际进出 run 仍沿源动画淡入。新测试既约束关闭辅助时的源姿态，又检查原生 AP 时间、真实移动、第一步与过渡附加残差，不能用“修正器有动作”替代正确源姿态。

旧源全鞋采样发现空/春/澪/和子的部分 walk，以及春 run 会穿过源平地，最深约 10.6 厘米。作者工具只重写双侧 UpLeg/Leg/Foot 六条源旋转轨道，保留原膝弯曲平面、脚朝向和上身，源鞋底目标为 8 毫米。导入采样采用显式 120fps；和子为保留新增源接触相位采用 240fps，优化和动画压缩关闭。

均匀平铺路面与已验证 walk/run 的小量高度差，允许不超过 25 毫米的共同 Hips 上移，保留源腿与衣物关系；真正高差、台阶、坡面和更大的抬升仍走每脚接地 IK。新反例验证旧运行时在 1 厘米路面会改变源腿姿，新方式只移共同根，全部相对骨姿保持。
