# 赴约、日切与保存恢复

2026-10-06。日历推进是一项可取消的赴约选择，不代表参加活动，也不代替照料作物。

## 已实现

- 首次集市沿用真实准备条件。夏祭要求Q05完成及澪实际呈现的邀请，不强制同时完成灯笼和空间两项目；旧档缺邀请记录，可当面再确认。花火读取实际19:30开场时间。
- 逐日执行原结算，每次日切在回调结束后保存一次。未浇水的空日不会假增长；半成品、预留与未做完的个人项目保留，公共准备由居民接手并分开记作者。
- 目标时刻在家中醒来，玩家自己出门决定参加。暂停日历可以停在已经结算且保存的日期，不倒退。
- 写失败停在待保存日。C提供独立重试，即使预约过期也能使用。同日跳时失败必须真正重写时间与位置，不重复结算。
- 普通睡眠先补写待保存日，再执行这一次新的日切；失败不展示成功睡过的提示。午夜重试能进入下一晨，载入24:00备份也会恢复一次午夜处理。
- 主快照损坏后，从有效previous恢复；下一次保存不把损坏current覆盖到有效previous。切换六槽时仍清除不属于当前槽的previous。
