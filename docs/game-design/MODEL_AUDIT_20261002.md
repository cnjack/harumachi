# 全模型巡检与建筑重做（2026-10-02）

本轮扫描游戏目录的 153 个 GLB，并生成每个模型的正反面图。逐张看缩略图，再对建筑、农园道具、动物和角色看近景与实际场景。最终改动 52 个游戏 GLB：Hyper3D 重做 7 件，另修复旧原稿减面产生的裂缝、重绘图集和统一材质。每个模型的处理记录在 `evidence/model_audit_20261002/coverage.json`，尺寸、UV 密度和拓扑数据在 `_audit.json`。

## 建筑：先分清比例和清晰度

旧导出主要是等比缩放，建筑变大没有直接改变长宽高比例。问题是大面积房屋共用图集，每米分到的像素变少，加上原模型的窗框、屋瓦和栏杆本来就有起伏。不能把这些问题都叫作拉伸。

重做 H01 玩家家、H02 公寓、H03 缘侧小屋和 S06 社区会馆。先从旧模型记录占地、层高和入口，再画规整的动漫正面图，从同稿编辑背面。四栋均用 High Quad、明确请求 5 万四边面；服务原稿保留，游戏版本约 3.6 万三角面。街区其余八种住宅和店铺检查后保留；旧 PBR 材质问题另作统一修正。

新游戏图集为 4096 方图，由服务原稿的 2K 底色重新烘焙。4K 是游戏图集大小，不能称作服务生成了原生 4K 细节。H01 和 S06 的小 UV 岛较多，默认留白浪费面积：间距改为 0.002，烘焙扩边为 4 像素，提高实际像素密度；不是单纯把图放大。

H03 初稿纸门偏矮且缺少格线。`finish_house.py` 在游戏尺寸下做分段高度校正：降低过高的缘侧，增加门板高度，保留占地和屋脊；纸门表面实测高度由约 1.28 米变为约 1.92 米，再补细木格。Hyper3D 可生成主体，门窗、人尺度和规则格线仍应按游戏近景修整。

四栋房屋与棚屋的边界保留在 `art/models/model_quality_contracts.json`，允许误差 1.2 厘米。原稿拟合系数最大/最小值分别约为 H01 1.011、H02 1.019、H03 1.178、S06 1.129；不是把差异很大的原稿随意拉进旧盒子。H03 的高度后处理独立记录在原稿目录的 `finish.json`。

- 内置 imagegen 重绘六种面包、两只猫和旧 A07 灯笼，共九张图集。面包改成干净的烘烤色与简化纹理，猫减少照片式毛发，灯笼去掉旧餐馆文字。七件只换图集，节点、网格、UV 与动画字节不变；两只猫先把新图集嵌入保留原 UV 的高模，再重新减面、展 UV 和烘焙。
- 修正 39 个旧模型的 PBR 材质连接。`matte_glb.py` 验证材质修改不改变节点、网格、UV、骨骼和动画；后续导出同样断开 Metallic、Roughness 和 Normal 的旧贴图连接。

本轮共接受七个 Hyper3D 任务，按每次 0.5 积分估计为 3.5 积分；没有购买积分。等待期间有一次网络中断和访问令牌过期，均使用原 generation_id 恢复，没有重复提交。准确的人民币扣款不在这份素材记录的验证范围内。

## 制作经验：先查导出，再决定花积分

本轮最重要的问题发生在减面。GLB 在 UV 接缝处分裂同位置顶点，关闭 OBJ 的 UV 导出不会自动合并它们。未合并就减面会产生大量开放边；原稿完整，游戏成品却像碎片。

`meshlab_decimate.py` 现在先在无贴图几何副本上精确焊接完全重合的顶点，再清理孤立点、减面。带材质高模保持原样，为低模重新展 UV、烘焙底色。门楼的开放边比例由 52.46% 降至 0.06%，烤箱由 48.22% 降至 0.01%；棚屋、鸟和角色也有同类旧缺陷。`weld: 0` 防止在带材质高模上进行有距离的合并，不表示减面副本也应保持 UV 接缝断开。

连通性阈值只用于指定的实心模型。叶片、组装家具和桥梁零件本来就可能有多个分量或开放面，不能批量当成破损。尺寸、面数和分辨率也不能代替画风验收；真正的门窗比例、背面完成度、字的朝向和场景关系必须看图。

生成经验与工具参数继续维护在 [HYPER3D_QUALITY_REVIEW.md](HYPER3D_QUALITY_REVIEW.md)。本轮使用的 21 张参考图和编辑图集在 `art/references/model_audit_20261002/`，完整提示词在 `art/manifests/prompts/model_audit_20261002_*.json`。服务任务、源文件摘要与最终三角面数在 `art/manifests/models_audit_20261002.json`。
