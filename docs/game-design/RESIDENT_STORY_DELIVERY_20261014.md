## 从一个发现到下一次邀请

安顿后即可打开卧室壁橱，看奶奶的信和写着“空和澪”的旧合影。相认如实交代已知的停办缘由；复办夏祭仍要在相认和第一次集市之后，由玩家明确接受。旧档已经开始的工作保留，不要求重新解锁。

第一次集市结束后在场地内回顾成果，并收到春家的具体邀请。新线索沿着“春家图纸与小葵的画 → 农园工具屋量木件 → 约定傍晚试坐 → 真实照片 → 澪的私人回访 → 寄信与两天后的回信”连续展开。任务页和HUD共用当前目标，预约时段另外保留，不被临时委托覆盖；导航会先指向当前房间的出口或正确的街门。

图纸不是照抄旧台子的命令。春希望坐着能看见小葵，玩家可以把一张真实长椅摆近，也可以留宽东侧通路。春沿实际通路走到座位，坐姿读取实际椅面，并检查到小葵的视线。和子带来小份餐食，街坊负责已有照明；这次试坐不要求玩家同时完成餐食和灯笼两套材料链。

预约为明确日期的17:00—20:00，避开傍晚冲突的节日和周六集市。取消、错过和补约保留同一笔借椅与已做的工作，街坊会先摆简便座位。完成照片比较后的寄信目标不会因再次预约而回退；旧档中已经完成的比较也会恢复到后续阶段。未走通、未坐稳或视线被挡时，不记录试坐成功。合影来自当时的真实画面；保存失败、丢失或损坏可以补拍，补拍会标明，不能用插图替代或直接宣布比较成功。

## 道具随事情变化

太鼓日常有罩布，练习时取下，结束后盖回；日常金鱼水槽保留练习用途，正式摊具只跟活动出现。低台保留，音箱和彩旗按开场状态显示，隐藏的附件不留下碰撞。盆舞台依木料、实际方案和开场时间经历搭建、开放与收场；居民代建明确归给田中与街坊，不能记成玩家完成。

木料从原堆转到工作处再变成成品；送来的面包和收获篮按真实交付批次、营业和收摊状态显示。公告、施工牌、苗盘、麦茶托盘也有用途和收起条件。撤去庭院与农园纯粹重复的箱桶组合；没有实际野餐邀请的湖边地毯收起。桥的基础灯与花盆继续用于日常照明。
