# 猫的模型、骨架和动作（2026-10-04）

> 2026-10-07：正式两只巡游猫已改为 59 关节、八权重蒙皮及新制作的 Walk/Idle，替代下文的旧 48 关节步态。新动作有爪部 IK、胸臀配合、左右张望和延迟摆尾；来源与验证见 [最新全身动作](CAT_LIVELY_MOTION_20261007.md)。下文保留原制作历史，不作为当前资源规格。

## 动作从哪里来

当前人物动作来自 `art/tools/rig_char.py`：程序定义步态、手势和关键帧。人物 T pose POC 将原游戏的 11 个动作迁移到新骨架，并保持原时长；没有使用 Puppeteer、Rigel3D 或 Mesh2Motion 生成人物动作。

这次猫采用不同的管线：Hyper3D Rodin 生成站姿网格，Blender 适配 Mesh2Motion 的 48 关节四足模板，并迁移其已有四足动作。Godot 负责行走路径、平滑转向、暂停和播放速度。不能把免费动作库说成文字生成动作的服务。

两张站姿参考保留原游戏橘猫、三花猫的花色，但四腿分开、身体展开，避免把睡姿或坐姿模型强行拉成行走。Gen-2.5-High、Quad、50,000 面目标、纹理 delight；实际 GLB 三角面统计见表。原始生成、请求、下载记录位于 `art/models/raw/cat_walk_20261004/`，来源记录在 `art/manifests/models_hyper3d_cat_walk_20261004.json`。

静态原稿经支撑面放平、转正、缩到约 35 cm 高，再降面。绑定仅增加骨架和权重，保留处理后的外形、UV 和颜色贴图，正式导出改为无高光、无金属与法线贴图的漫反射材质；没有把模板猫网格混入导出。每顶点最多四个归一化权重。动作迁移按目标骨骼参考姿态计算旋转，按父骨空间迁移位移；去掉平面根位移，用实际蒙皮爪部采样校正地面接触。Walk/Idle 用于正式巡游；Run/Sit/Jump/Sneak 已导出并拍摄多方向、多相位，但尚未接入追逐、跳障或受惊状态。

游戏资产为 `game/assets/models/AN_cat_orange_walk.glb`、`AN_cat_calico_walk.glb`。可编辑 Blender 文件、脚本和独立 Godot 预览位于 `art/poc/cat_motion_20261004/`。动画资产走独立绑定导出，不送入静态 `game_export.py`，以免丢掉骨架与动画。

用户要求质量重要的模型使用 Hyper3D。此前两次 Pixal3D 猫生成仅作为归档对照，不接入游戏或菜单。简单道具的 Pixal3D 质量评估留作后续研究，没有新增自动任务。

## 游戏里的四足走动

`ambient_life.gd` 通过 `WorldBuilder.spawn()` 加入两只站姿猫。橘猫巡游矩形为 x=19.2–20.4、z=54.4–55.6；三花猫为 x=19.2–20.4、z=68.4–69.6。`cat_walker.gd` 以 0.12 m/s 走路、平滑转向，每四个路点暂停 1.6 秒；按资产的原生步速调整 Walk 播放速度。碰撞形状有 `model_part` 标记，使用实际地面和实体碰撞。只在白天的镇子中活动。

原睡猫、坐猫保留原来的休息和注视行为。新猫是环境巡游，暂未增加追玩家、喂食、导航寻路或新的奖励规则。

## 菜单只播放 2D 动画

按用户最后的要求，菜单使用透明图集和 `AnimatedSprite2D`；运行时不加载 GLB、骨架或 3D SubViewport。橘猫在标题插画的前景石路左右走，到端点停一下再转向；不拦截鼠标，不占键盘焦点。

试过将 Hyper3D 猫离线烘焙成 24 帧 Walk、8 帧 Idle 的透明图集。侧面轮廓和头部姿态不够贴合标题插画，保留为拒收对照。最终采用按橘猫参考图生成的八帧走路、四帧待机动漫平涂 2D 帧；素材、SpriteFrames 和制作记录放在 `game/ui_kit/`，提示词记录在 `art/manifests/prompts/cat_motion_20261004/`。

## 验证与边界

两只猫的资产检查通过：48 关节、无坏权重、外形与 UV 保留、六个动作时长与源库一致。支撑面倾角橘猫 0.02°、三花猫 0.32°。实际主场景中两只猫各走约 4.64 m，经过四个路点并转过四个方向，脚下根节点距地面约 1 mm。26 项 LIVING 测试通过。证据在 `evidence/cat_motion_20261004/asset-contract.json`、`cat-reference-level.json`、`world-roam3/` 和 `living-tests.json`。

这条管线验证了现有动漫网格接免费四足动作的可行性。动作来源是通用狐类四足模板，步态尚未逐项对照真实猫；自动权重也不能保证极端姿态或所有尾部动作都合格。当前接入的是慢走与待机，不宣称已完成完整宠物行为系统。

菜单十项独立检查通过，包括无 3D 节点/视口、实际帧变化与位移、端点待机和返回、鼠标穿透、键盘焦点，以及设置/完成按钮的真实 GUI 输入。旧 3D 菜单在新检查中失败。16 项 UI KIT 回归与界面样式审计通过。原生 16.1 秒、30 FPS 录像为 `evidence/cat_motion_20261004/title-cat-2d.mp4`；截图与遥测见 `menu-2d/`。独立猫检查不改变主测试集的 616 项计数。
