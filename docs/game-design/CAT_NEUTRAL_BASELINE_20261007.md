# 猫的中立姿态与头颈归中检查（2026-10-07）

用户指出头和身体不在同一位置，像向右歪着、向左看，要求头正常朝前微微向下，拍上下左右四个角度，并允许重做质量更好的模型。本轮先关闭张望，增加正面、上方、下方低角度、左侧、右侧五张原生截图；每张同时显示原网格、旧停走基准与归中试验。没有把概念参考图称为 3D 模型截图。

## 两个来源

原模型在未使用骨骼动画时也带着侧转的头与不对称的站姿。原 image-to-3D 参考图确实是身体朝侧面、脸看镜头，因此该方向差已经进入网格。`views/` 中第一列直接移除 Armature 变形后导出，保留原顶点与贴图；第二列是正式资产 Idle 第一个时刻；第三列是归中算法候选的同一时刻。

旧姿态代码还存在第二个问题：先绕世界 X 低头，再修正原模型的脸部偏航，使一部分低头变成侧倾。旧橘猫两耳根关节连线侧倾约 8.19°。头的旧支点来自前额区域的顶点中位数，转头时又绕颈部摆动，橘猫的头部参考中心偏离颈部最大约 3.11 cm，三花猫约 7.61 mm。

归中试验先把源脸部转正，再低头；用耳根中点向前 12 mm 的位置作为颅部参考中心，置于颈部中线上。运行时围绕颅部自身转头。`alignment-before.json` 在旧资产上触发偏移与转动漂移检查，`alignment-revised.json` 在两种片段各 61 个时刻、正负 50° 与回正姿态上复查：参考中心偏差约 1.15/1.75 mm，转头中心漂移小于 0.001 mm，耳根关节连线不再出现额外侧倾。

上述数字描述关节和颅部参考点，不能证明眼睛、耳朵外形或胸背的原生网格已经完全对称。五个角度仍显示原模型本身的姿态与形体偏差，因此没有将该试验声明为最终正常模型。
