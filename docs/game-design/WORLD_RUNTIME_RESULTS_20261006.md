# 位置、出现与轨迹观测（2026-10-06）

`--spatial-report=/绝对路径/report.json` 开启只读观测器。逐帧检查人物、巡游猫、鸟和昆虫的碰撞与扫掠；每 0.2 秒记录模型/程序网格、可见状态、位置、出现顺序、物品身份、移动、移除及切场跳变。生成的模型带有 WorldBuilder 的创建序号；首次发现时间不冒充创建时间。

`--world-audit` 使用声明过的日期/时刻/站位夹具，运行 D1、D2、D3、D7 六个时段及集市路线。并非自然连续游玩，也不覆盖所有存档、天气、料理和摆放组合。

首次完整观测发现 14 类碰撞候选。修复昆虫花丛内出生、鸟/虫缺少角色避碰、空中动物受阻恢复，并将静止动物探针放到实际模型底面以上。猫随机起点完整遍历常见区域，全部被占用时隐藏等待；日程行走在搭话时暂停，失败后释放日程缓存以便再尝试。鸟必须实际到达且有地面支撑才能播放地面动作。

复验记录 4446 个对象、2703 次采样，退出 0，无 SCRIPT ERROR 和负尺寸 AABB 错误。剩余 1 类接触是墙上睡猫与墙的玩家阻挡体：可见墙身高 0.70 米，瓦帽约 0.855 米，猫底约 0.855 米；玩家阻挡体按既有规则加高到 1.20 米。原生 `keepout-review/placement_sleep_cat.png` 确认猫伏在瓦帽上。保留这一接触记录，没有通过排除它伪造零接触。

结果在 `evidence/world_runtime_audit_20261006/multiday-recheck/`。440 个静态 AABB 相交候选尚需逐项按网格和截图分类；相交候选不等于穿模，身体碰撞通过也不能证明整场景没有重叠。固定休息动物的出勤变化、雨天长段观测及完整故事路径仍待补充。
