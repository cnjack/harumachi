# 建筑材质与近景修订（2026-10-03）

本轮保留前一轮 Hyper3D Rodin 生成的 12 类建筑形体、独立门窗和六个公寓住户模块，补齐其余店铺与住宅的贴图细节。没有提交新的收费 3D 生成任务。Blender 负责材质烘焙和导出，建筑主体的来源仍是 Hyper3D。

## 实际改动

- 面包店：黄帆布遮阳篷缝线、砖缝、铜管接头、门把手磨损、窗内面包。
- 花店：薄荷绿旧漆、细叶藤蔓、窗内花束和盆栽、玻璃棚的动漫天空色。
- 邮局：红门与邮筒磨损、灰泥修补、木料钉头；招牌仍是独立的可编辑文字。
- 杂货屋和町屋：木格栅、竹帘纤维、靛蓝暖帘、风铃和瓷器陈列。
- 公民馆与两类住宅：短窗帘、竹帘、木窗五金、墙面修补与生活陈设。
- 奶奶家、廊屋、公寓和商店：保留已完成的分件结构，补全侧面、背面和屋顶的细材质。

## 贴图为什么这样做

一张 2K 图覆盖整栋六至七米高的建筑，近景很容易发糊。把它插值成 8K 不会产生新细节。本轮先用 imagegen 编辑各立面的正交图片，再生成杉木、灰泥、瓦釉和布料四种真实绘制的细节图，按世界坐标的米制尺寸取样。Blender 以原始 UV 烘焙这些新内容，稀疏的大表面用 8K，小表面用 4K，原本足够清楚的门窗和住户模块保留原图。

木纹、灰泥和瓦釉使用连续像素权重混合，避免按整片三角形换材质后出现锯齿边界。木材权重还按色彩饱和度过滤浅色墙面；布纹缩小强度并放宽采样间距，避免摩尔纹。屋顶保留原始瓦缝，只叠加细小釉面变化。不同表面各用各的材质，不铺统一噪点。正面图案另用 BVH 射线可见性遮罩，避免在前景风铃后方的墙面再次绘出同一风铃；遮罩的临时顶点色导出前删除。町屋按原 UV 匹配 20,000 个对应点求逆变换，消除转正后的投影偏差，99% 对应残差小于 0.01 毫米。

原始文件在 `art/models/raw/scene_rodin_20261002/`，新文件在 `art/models/raw/material_detail_20261003/`。图片在 `art/references/building_materials_20261003/`，完整提示词为 `art/manifests/prompts/building_materials_20261003.json`，来源记录为 `art/manifests/models_building_materials_20261003.json`。使用内置 imagegen 工具，输出都已复制进工程。

## 可复用的制作经验

1. 整栋生成负责房屋比例和不规则轮廓；玩家会靠近的门窗、货架、扶手优先独立生成。大楼分件时按真实尺寸规划接缝，统一缩放，不能为塞进旧包围盒而拉伸各轴。
2. 贴图编辑必须附实际正交渲染，锁住画面边距、门窗位置和每根窗条。漂亮的概念图不能直接当贴图；投影后的门把手、窗条和瓦缝必须逐项看有没有双边或错位。
3. 文本单独做可编辑招牌，不让生成服务猜字。玻璃内部继续使用游戏里的房间映射；画出的陈设不会变成可进入的室内。
4. 细材质按米铺设，保留原图的大尺度色彩与木板、瓦片接缝。先做一栋看近景，再批量烘焙。不要用三角形中心的 RGB 粗分类整片屋顶和灰泥。
5. 贴图密度、面数和分辨率只负责筛掉明显不足。最终仍看四个方向、两米门前与檐口的实机截图。增加的材质细节不能修复主体轮廓上已有的软边。
6. 检查源纹理和最终纹理的实际像素差异；本轮的 `material_detail_check.py` 在真实 UV 覆盖区域与插值后 JPEG 重新编码的控制组比较高频残差，排除只插值放大的结果。这个量本身不评价画风或美术水平。
