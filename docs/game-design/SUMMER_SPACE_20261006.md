# Q13 当前场地的三种需要

2026-10-06。Q13新增空间实践切片，目标仍是完整夏季约四小时与十一维好玩标准，当前不能标整篇达标。

## 实现

新主线中，春交图纸后可以白天与田中确认分工。田中与街坊搭台，玩家安排观看、入场与供餐；傍晚的私人往事可另外听，搬木改为自愿劳动，不以六根木料替代场地试用。

旧布置区只到z=12，舞台在后方，无法产生真正的舞台占地取舍。新项目有独立区域x[-11.5,11.5]/z[12,24]；退出编辑恢复旧区域。舞台、两座夏祭屋台用按模型尺寸的透明占地预览和实际碰撞表示；盆舞圈在地面显示，桌椅放在圈外，固定棚、舞台与设施也查当前碰撞。Q11以前场地入口不显示具体内容。

手工路线复用B摆放、旋转、收回和撤销。轻操作路线可预览、比较与采用两种草案，之后仍能微调：东侧有附近可放盘的桌面；西侧示范看得近，纸包在北侧取。草案只是实际安排，不替代试用结果；借桌椅只发一组，互换回收已有家具，失败回滚原方案。

当面约到实际在場的澪、春、莲，才可看这一轮。演出切到各自起点的准备不记作走过；随后使用当前碰撞的实际路线和NPC.walk_safe。澪从入口到示范点，春从菜圃到观看停点并用真实头部位置观察澪，莲从取餐处到供餐停点。观看停点明确是站立试看，不假称已经坐下。盘子模式要求取放处在观看点5米以内；纸包可以更远。观察支持快看、Esc或按钮中止，半方案不丢。

好初案三项成立即可保留，不要求返工。记录绑定布局、供餐方式和家具身份；摆动之后失效。夏祭/共同排练再用同一方案，供餐与观看路线要绕开正在使用的盆舞圈。存在一个合法初期方案能借圈通过、共同使用时不再连通的案例，说明新增条件不是自动通过的摆放计数。不同日期、夏祭与排练各自保存活动身份，不合并成假参加。

旧档完成Q13可从场地纸签补做新实践，不回改旧主线；启动后仍能邀请实际演员。项目家具收回/重摆会同步UID归属，避免草案互换一直报旧家具缺失。临时编辑与活动记录分开，实际成果不等于亲自搭整座台子。
