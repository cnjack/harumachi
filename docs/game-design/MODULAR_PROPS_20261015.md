## 模型与材质

13个单体为MS01—MS13；P_signpost、R09及MS14_event_board是3个本地组合导出。R06保留原候车亭主体，仅删除经连通分量和实际边界确认的独立旧蓝站牌，不重建整座候车亭。游戏GLB总数从278变为292。

木牌有真实厚度、圆角与支撑；箭头可分别翻转，文字投影绑定每个箭头的局部空间。霞鹜文楷蒙版形成暗字口、亮边与局部法线，正反面各自正确阅读，不叠浮空Label3D。背面文字避开木柱。公交线路表保留清晰排版，属于实用信息；不要求将其做成难辨的装饰。

格柜由43个独立开口格拼装，柜内物品按真实层板三角面计算接触高度。碰撞体覆盖柜体，留出原来的通路。抽屉以真实下层板为支撑，照片平面嵌在真实木框凹槽内，柜台立牌与墙框分别记录实际柜台、墙面；标记本身不能使悬空物件通过摆放检查。

源模型准备仅做比例、基底放平与面数控制，保留UV和图集；导出使用JPEG，不能将“保留原贴图”写成导出像素完全相同。具体尺寸、离线重建与接入例子见[资产源目录](../../art/library/modular_props_20261015/README.md)。
