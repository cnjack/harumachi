## 适用的制作方式

1. 先拍实际游戏，固定机位、时间、天气和画面尺寸。对已有足够元素但质感不足的场景，从完整截图开始，而不是逐件盲目生成。
2. 用 imagegen 改绘截图，保留道路、功能位置、尺度和人物身份。要求明确的木板接缝、支架与连接、石材厚度、植物疏密、不同新旧程度，以及真实光影关系。
3. 用户确认方向后，把改绘拆为形体、材质、植被分布和光照四类修改。模型数量、面数和贴图分辨率只用于控制成本，不代替画面判断。
4. 有机主物件可用 Hyper3D；梁柱、平台、楼梯、可用桌面等需精确尺寸的构件用 Blender 整理。透明叶片、水面和文字分别处理，不能让生成服务把它们黏成实心物体。
5. 每轮都拍原机位，再拍玩家距离的近景和背面。检查鼓皮与鼓身、鱼池内外、藤叶与棚架、草坪边缘、根部接地、围栏底部；补黄昏和夜景。原图、改绘、实景三者一起判断。
6. 结构或摆放问题变成回归检查，先确认旧数据或错误候选会失败。视觉仍需亲眼看，不能只凭测试通过结束。
7. 最后验证支撑面、碰撞、交互与居民路线、真实渲染帧时间。导出包仍遵守解压后完整 `--autoplay` 退出 0 的交付规则。
