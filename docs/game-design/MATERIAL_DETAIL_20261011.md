# 墙、铺石、水面与日常道具的材质细化

本轮方案经用户确认后实施。方向是清爽的夏日动画老社区：物件有人维护，受潮和磨耗只出现在实际接触土地、植物、雨水和经常使用的位置。

源码按用户要求先提交。真实网格闭合、40项专项与1538项独占全量已通过；40项在旧场景失败38项，修后零失败。新macOS包已通过ZIP、解压、签名与双架构检查。Mac锁屏使最终原生复拍与解压包200项演示待完成，正式桌面包尚未替换。当前状态见`evidence/material_refinement_delivery_20261011/progress.json`；待完整验收通过后再建立delivery记录。

## 已实施的内容

- 墙脚按每段墙的真实底面设置局部潮痕，范围10–35厘米；石基与墙柱共享同一接触位置。少量苔藓有厘米级纤维轮廓，上部墙面保持干净。
- 石路保留原铺石与接缝，磨耗对应八个真实入口，墙边有少量尘土、落叶和门边鞋刷。草地与通路尺寸不变。
- 木牌按板和立柱分别安排纹向，补端面、固定件和旧漆。公告栏只处理木框，保留纸张、绿板与蓝瓦；三处箭牌的正背文字均贴在真实板面内。
- 水面由真实深度控制浅、中、深层次，浅水能看到实体底石。太阳、月亮和实际桥灯只在反射路径上产生碎光；细雨圈使用连续世界坐标计算抗锯齿。
- 河石分露岸、半浸和水下石组，以实际脚印检查道路、四处钓位和抛线通路。
- 榕树摊位改为连续蓝白帆布，补折边、缝线和绑绳，保留完整柜台及其支撑。遮雨高度图来自实际屋顶三角面。
- 烤箱拆分金属、门封、玻璃、炉腔与操作面板，重建平直门框、水平把手和圆形旋钮；外壳、完整排气管与实际部件接触已修复并验证。

六张材质均由内置imagegen生成或编辑，原始PNG未做像素加工。实际分辨率为1254×1254，2048只是模型导出的纹理上限。来源、提示词和SHA记录在`art/manifests/images_material_refine_*.json`、`models_material_refine_20261011.json`及`images_codex.json`。

## 本轮发现的验证陷阱

只改基础水面shader不够：当前选择的B方案还会替换它并覆盖透明度。现两入口共享水面实现，检查实际运行材质及其include依赖。

`ShaderMaterial`可以保存未声明参数，深度纹理也可能被普通uniform列表隐藏。必须核对真实声明、读取路径及GPU开关对照，不能把get/set成功当作画面已生效。

本机Forward+实际mat4上传需要显式`Projection`。原`Transform3D`在原生雨shader中返回单位矩阵；CPU检查仍通过，棚下却继续有雨。修复后两套独立对照均为棚下7条全部消失，棚上7条和外侧2条保留。所有同类木材局部矩阵也已统一检查。

雨圈的导数不能来自包含hash和floor跳变的距离。第一版数值跨度通过，但人工检查发现方格；新增长直边检测抓到旧图4.24米的横边，改用连续坐标脚印后最长约11厘米。

湿痕需要在真实光照下可读。初版平均只有约4级RGB暗差；调整局部湿色后约7.76级、强区域14.38级。50/58厘米上墙400个采样像素完全不变，42厘米过渡边缘的两处1级差单独记录。

只看烤箱正面会漏掉顶部与后壳切边。贴图、轮廓和八项门框检查通过，仍不能替代实际拓扑测量；闭合模型已补看顶部、完整后壳与排气管；原两张过近背面仅计材质细节，另外以两张宽机位核对整体。最后的旋转椅背纹向修复后仍需再复拍最终冻结源码。

旋转木件的纹向必须与采样坐标一致。末轮审查发现咖啡椅背已转到父物件Z轴，选纹向却还看网格局部X轴；现用同一变换后的尺寸选轴。新增回归直接读取真实左右椅背的材质axis=2，旧场景返回0。
