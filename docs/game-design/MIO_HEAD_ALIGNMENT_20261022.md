# 澪头颈与眼线修正（2026-10-22，v21）

用户指出 v20 脖子歪、眼睛斜，整体观感异常。上一轮格式、连接及帧率通过，不能代表头部自然度被用户接受；v20 的转面幅度和持续歪头已在本轮撤回。

## 原因与修改

- v20 同时改变脸颊、眼窝、鼻尖、下巴位置，再通过 Head 父节点整体横移。极限转头实际下巴偏移 17.03 px，颈中段偏移 12.35 px；这些变化把颈部拉成斜带。
- 移除 Head 父节点的水平位移，俯仰整体平移从每参数单位 0.25 px 降至 0.08 px。收敛源脸颊与下颌关键形，实际下巴横移限制在 7.5 px 内、颈中段在 5 px 内；领口固定。头发、耳根和眼窝同时调整，避免只有脸向一侧滑动。
- 远侧眼宽从 88% 恢复到 94%，近侧保持 100%；眼距压缩从 7% 减为 3.5%。左右眼使用同一垂直基准，保留原画的虹膜、眼睑、眉毛及正面轮廓。
- 删除待机正弦歪头和 motion3 播放后的重复侧倾。招手、思考等明确动作仍保留各自的轻微头部姿态；左右看由水平转面表达。
- 修改写进正式 CMO3/MOC3 和五组 motion3，思考食指目标随下巴同步重烘焙。58 部件、38 参数、0.736 头部比例、原衣袖拼接、加油前臂内收及已移除的伸懒腰保持原状态。

## 验证

证据目录：`evidence/mio_head_alignment_20261022/`。

- 新 `HeadAlignmentTests` 先跑 v20 模型，出现 111 条失败，捕获过大的颈部、下巴、眼窝位移与待机侧倾；正式版 95 项 Swift 检查中 91 通过、4 项可选网络跳过。
- 35 张固定视线 Core/Metal 截图逐项对照。中性头部与颈部以下图像均逐像素一致；`head-before-after.png` 上为 v20、下为 v21，`head-grid.png` 包含全部角度。
- 6,514 张动作帧及 25 组切换，检查连接带 781,680 像素，最低 alpha 254，最大接点误差 0.000137 px；13,028 个皮肤带无暗线失败。目视查看五动作与视线极值对照，思考姿势食指仍接触下巴。
- 3,240 个表情/动作/视线/眨眼组合、360 张 Metal 图，无网格翻转或连接失败。
- 现有真实显示器持续播放 40.64 秒、2,421 帧，平均 59.57 FPS；九种状态通过，正面和左右看时头部 roll 均为 0。测试静音、未创建虚拟显示器。
- 网页手动正面/左右预览现在覆盖待机视线曲线，避免点击“看正面”后仍被 Idle 曲线带偏；跟随视线模式保持动态。
- 原桌面来信和网页使用相同正式运行文件；最新网页测试、资源摘要与提交结果写在同目录 `verification.json`。

本轮目标是修正歪颈和持续侧倾，采用较克制的轻度转脸。这里记录几何、运行及目视检查结果，不把它们当作用户对自然度的最终认可。大角度侧面仍需要专门的侧面原画。

## 复现

```bash
python3 art/tools/live2d/export_mio.py --work /tmp/mio-head-alignment
bash native/mio-companion/tools/build_app.sh
native/mio-companion/dist/Mio.app/Contents/MacOS/MioCompanion --review-head /tmp/mio-head-alignment-views
```

`MIO_HEAD_FIXTURE` 可让回归检查和固定角度截图加载独立模型，用于验证旧模型负例。
