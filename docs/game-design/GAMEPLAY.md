## 首轮剧情与供货更新（2026-10-01）

新增可选委托 Q16「莲的街坊三明治」。Q05 首次集市、Q06 河边农园都完成后开放；面包店前左侧推车上的试吃纸签是入口，也可以按 J 接受。委托列表可以滚动，新任务不会挤出窗口。

流程：接受少量试做 → 领取一次免费材料（番茄 2、黄瓜 1、面粉 1、黄油 1）与配方 → 在店内烤箱做一份三明治 → 带给莲切成三份 → 请澪、春、和子中的任意两位试吃 → 选周六菜单 → 留番茄 2、黄瓜 1，在周六 16:30–22:00 的庭院摊位交给莲 → 第二天回试吃纸签看后续订单。和子在店里时从商店柜台交试吃。

两种菜单是“菠萝包为主，三明治少量试吃”和“街坊三明治为主，也留菠萝包”。选择改变店内纸签、集市纸牌与篮子里的面包/三明治比例，材料报酬相同。供货采用当时的集市价格与全局同物品卖量递减；实际交付一次才支付一次。

试做材料、做好的试吃三明治和已接受的供货数量会预留。商店“卖可售部分”、无人菜摊、集市出售、送礼与其他料理保留预留；订单界面写明数量。试做三明治本身可以使用这一份预留材料。背包满时材料保留在莲那里，不会给一半就丢掉另一半。

可以去纸签改约，或让莲用店里材料，取消预留；后一种不发玩家供货的钱，首次试吃剧情仍继续。集市后的第二天可以接下一篮，也可以休息，不影响主线或熟悉度。委托、菜单、试吃名单、订单日期、供货记录都随 v4 数据存入现有 SQLite；旧存档自动出现新邀请，不假装玩家已经参与。

夏祭散场或晚开始时，Q14 仍可找澪另约树下一晚，补捞金鱼和合影；不补记盆舞或亲自参加。错过花火后，Q15 可在河边长椅听田中讲那晚的记录；不补记亲眼看过花火。HUD 和任务详情同时给出继续入口。三种金鱼摊回答都成立，后续对话记得玩家选了来年一起、回来时见或先留照片。

## 玩家体验与动力

玩家是刚搬到晴町的新住户。通过认识邻居、完成小事、布置共享庭院，把一个冷清的庭院变成大家愿意停留的地方。v0.4 起时间会流动：每天约 12 分钟，睡觉进入第二天，周六傍晚办集市，第一次集市之后生活继续。没有体力值，作物不会枯死，熬夜也只是迷迷糊糊回家睡觉。

核心循环（每天）：起床 → 浇水、收菜 → 和邻居聊天、送菜送料理、做公告栏委托 → 去商店买种子和调料、在厨房或莲的烤箱做料理 → 周六傍晚去集市摆摊，赶上节日就去过节 → 回家睡觉。种植、料理和节日的完整设计见 [FARMING.md](FARMING.md)，数值和平衡见 [BALANCE.md](BALANCE.md)。

## 委托状态规则

- 状态：锁定 → 可接受 → 进行中 → 完成；步骤只能前进，读档不能重复领奖（有测试覆盖）。
- 任务物品（钥匙、篮子、种子、洒水壶、标牌、标记）放在背包“重要物品”区，不能出售或丢弃。
- 交付是原子操作：检查物品 → 扣除 → 发奖励 → 推进步骤，中途不会留下半完成状态。
- 快速连按交互会被忽略，直到上一段对话结束。

## 布置模式

- 进入：Q05 期间走到庭院中间的告示牌，按 B 或 E。镜头切到俯视，显示 0.5 米网格。
- 数字键 1–5 选物品，Q/E 旋转 90°，左键放置，F 收回鼠标下的物件，Z 撤销本次放置，右键或 Esc 退出。
- 合法性用颜色加文字说明：超出区域、与其他物件重叠、挡住走道、压到树根都会写明原因，不只用红绿色表示。
- 布置区 x −1.5..9.5、z 2..12（庭院中部），树下 1.5 米半径和西侧从入口通往摊位的走道（x −1.5..0）为禁放区。集市开始后布置锁定。

自动存档点：完成委托、睡觉、在床上存档、暂停菜单保存。进度和设置保存在 `user://harumachi.db`（SQLite），进度数据仍是 v4，包含位置（家里 / 小镇 / 农园）、委托、背包、货币、熟悉度、布置、作物、小游戏、天数和时刻，以及成就、旧物和图鉴。数据库用事务保存，保留上一份快照，并用 `harumachi.backup.db` 备份完整数据库；当前快照校验失败或数据库损坏时恢复备份。

旧版 `save.json`、`save.bak` 和 `settings.json` 首次启动时迁移到 SQLite，原文件保留，迁移不会覆盖已有的新进度。v1–v3 存档仍能读取。桌面版的存档目录继续使用原来的“晴町日常”。网页版使用键鼠，存档保存在当前浏览器中，不是云存档；清除浏览器数据也会清除进度。网页顶部的“保存进度”按钮也能保存。

开始游戏、读取进度和搭建场景时显示灯笼加载界面及实际进度；进入家、商店、面包店、农园和返回街道时显示简短的过渡提示。加载结束会恢复输入和游戏时钟。

## 时间、天气与邻居的一天（v0.4）

- 06:00–24:00，现实 0.67 秒 = 游戏 1 分钟。床：18:00 前可以“午睡到傍晚”（16:30），18:00 后“睡到明天早上”，睡觉自动存档。24:00 会自动回家睡着。
- 天气每天固定（按天数作种子）：晴 60%、多云 25%、小雨 15%；第 1–3 天和每个周六一定是晴天。下雨自动浇透露天的地（温室除外）。家里的电视会报明天的天气。
- 光影随时刻连续变化：清晨暖光 → 白天 → 傍晚金色 → 18:30 路灯亮 → 夜里月光与星空。多云和下雨会降低阳光、加雾、降饱和度，下雨时镜头周围有雨丝，环境声换成雨声；夜里换成铃虫和蛙鸣，农园是河水声。
- 邻居作息：澪上午在公告栏，12:00–13:20 去花店，18:10 后在庭院南边长椅；莲在面包店到 18:20，然后来庭院坐坐；春上午会蹲下照料花圃；田中爷爷在农园工具棚、菜地和河边；小葵第 2 天起上午陪春、下午去农园抓蜻蜓、傍晚在沙坑。21:00 前后大家都回家（看不到也不能对话，委托标记也不会指向不在的人）。
- 邻居站着时会张望、伸懒腰；当天第一次见到你会挥手（春和田中鞠躬，小葵欢呼）；说话时有手势，照料作物时蹲下。
- 周六 16:30 以后是集市：第一次由澪开场（剧情演出），之后每周六自动开张到 21:00。

## v0.5：经验、商店、料理、背包、节日

- **种植经验**：翻土、播种、浇水、收获都加经验，10 级。升级卡片列出解锁内容：2 级番茄/黄瓜/土豆和两道菜、可以扩租农园；3 级毛豆/洋葱/小麦、可乐饼、铜洒水壶、小院扩建；4 级茄子/玉米；5 级草莓苗、天妇罗、咖喱、旅行背包；6 级南瓜、温室扩建；7 级西瓜、金洒水壶；8–10 级是收获和卖价的小加成。
- **商店**：晴町商店（种子、调料、升级）、莲的面包店（面包、配方卡、烤箱、石磨）、花店、杂货铺、田中的种子铺（常用种子、草莓苗、小院和温室扩建）、夏祭摊位。都用同一个带横幅的买卖界面，有营业时间，商店周三休息。
- **料理**：家里厨房 16 道、莲的烤箱 8 道、石磨 1 个。做料理会拨动时钟（10–90 分钟）；做好的料理能卖、能送人（温度 +2，最喜欢的 +3），集市上 1.3 倍，夏祭摊位 2 倍。
- **背包与金币**：每格最多 99 个；家里走廊的收纳箱 60 格；每种东西在同一个买家那里一天超过 12 个就打七折；金币变化时 HUD 上会冒出 +/− 数字，早上的卡片总结昨天的收支和经验。
- **节日**：七夕（许愿短册）、蔬菜品评会（交作物比分数）、夏祭（盆舞台、屋台、2 倍摊位、盆舞）、花火大会（河边选人一起看）、灯笼流（从桥上放灯笼）、月见（供团子）。每个节日都有专属台词和一次性奖励，详见 FARMING.md 第 14 节。

## v0.6 反馈之后：邻居的活动、站位和去农园的路

- **邻居在集市和节日里会动**：每人一条循环路线（`Layout.MARKET_ROAM`、`festivals.json` 的 `roam`），每站停几秒，做一个动作或换一个站姿。集市上澪在自己的摊位前招呼、到庭院中间张望；莲在摊位间来回；小葵跑来跑去伸懒腰、拍手；春和田中爷爷走得少；和子阿姨在庭院西边逛到摊位旁。夏祭上小葵去捞金鱼、到莲的屋台买东西、在盆舞台边拍手，澪去田中爷爷的屋台；七夕大家在竹子前挂短册、聊天；灯笼流时春和田中爷爷在河边鞠躬；花火时大家沿河岸走动、抬头看。屋台摊主（夏祭的莲和田中爷爷）、品评会主持澪不走开。
- **不挡路、不穿人**：走路时会绕开玩家和别的邻居；玩家正挡在路上时先停一下（最多 1.5 秒），再从旁边绕过去。玩家站到邻居 2.4 米以内，邻居就不出发，方便说话。对话、过场、转场、打开界面和盆舞时，所有路线暂停。
- **站位规则**（测试 CLEAR 自动检查）：每个停留点离道具碰撞体、离玩家常走的主路（庭院门口 → 中庭 → 摊位前）至少 0.8 米，离同一场合别人的停留点至少 0.9 米；每一段路线不穿过道具。集市开场的过场里，玩家站在主路旁边，邻居走进来的路线离玩家至少 1.4 米。
- **去农园的路**：主街东头的墙开了口，立着和农园入口同一座灯笼门，门外的小路往下坡、进树林；在门下按 E 下坡。到了农园，玩家站在灯笼门里侧、面朝农园；回去时从农园的灯笼门出来，回到主街灯笼门里侧、面朝主街。农园那头的小路往上坡进树林，两头看起来是同一条路。
- **从店里出来**：在门口按 E，或者直接从门口走出去，都会回到主街店门前。店门外画着的街面下面也有地面，走不出去。无论在镇上、农园、家里还是店里，万一掉到地面以下，都会放回刚才站过的地方。
