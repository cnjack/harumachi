## 当前行为

合作记录绑定当时采用的桌椅身份与位置，沿用时检查保存路径各点和各段的实际胶囊碰撞。新固定设施、节日布置和摆放物都会参与检查；短暂经过的角色不会永久取消旧经历。障碍移走后，旧路可重新适用，不补造演员又走了一趟。

场地按人记录需要：澪的入场与示范位置、春的观看长椅和实际眼高视线、莲的取放桌与盛法；盘子方案还检查长椅到桌面的距离。只移动取餐桌，未受影响的澪和春记录保留；只补莲。供餐方式变化只影响相关需要。共同使用身份按活动与日期保存，局部桌椅变化不再清空同次活动的全部参与者。

新记录必须带非空、走到终点的路径，春还必须带完整视线坐标；取消、半程或缺测量不能升级为已试过。旧记录保留旧身份；其已有路径/视线继续检查真实障碍，不填造新观察。物理节点重建后，测试等待固定帧再判断。
