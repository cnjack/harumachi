## 玩家得到什么

喝过春的麦茶后，旁边的小桌成为实际可用的歇脚处。春用一句话介绍它；玩家拒绝回请也能使用，不要求先做一轮浅渍。旧档有喝茶记录时也开放设施，不补写过去的回请、制作或共同吃饭。

玩家可以在家吃，也可以把持有的普通料理带来，在小桌选择吃一份。春不在仍可独自吃；主动到麦茶处选择带来的饭菜时，春实际在桌旁才接共同回应。普通NPC聊天只保留原来那次回请的续用，不因背包有普通饭菜就反复弹吃饭菜单。

原料、收纳箱里的食物和已预留的份量不能当作当前可吃库存。每次只扣实际选择的一份，沿用现有消费与存档流程；不增加免费材料或故事批次。普通食物的回应只说“带来的这份”，不冒称是春的回赠或玩家亲手制作。独处不产生共同知情。

吃饭继续用饭菜到空盘的1.8秒近景。普通食物使用经过实际支撑检查的空角，避开茶托盘和当前两只故事碗，不把另一人的食物藏掉。消费入口也检查桌子实际可见，缓存高度不能替代当前桌面。

这项能力让已有厨房和料理有一个可重复使用的日常去处，没有新增四小时容量声明。首次、熟练再用、独处与共食的自然意愿仍待普通试玩；本轮不计新增分钟。
