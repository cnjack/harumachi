# 素材库接入与可见范围覆盖（2026-10-12）

本轮接入前次评估推荐的17个单体：10种草木、纸箱/桶/小凳、3种碎石和一档低模悬崖。它们有实际场景位置，草木同时用于近景和外围散布。小镇整理角、农园工具棚使用新小物；湖边有贴合地面的格纹布，水桶里有浅水。两/三阶阴影、克制的轮廓光、简化木纹、格纹和水面波纹由独立Godot着色器实现，没有复制Blender节点图。课程包只参考参数化与分层方法，没有复制课程文件。

## 可见范围

普通镜头、拍照镜头和摆放镜头共用210米远裁剪。晴天85米开始雾化，190米完全遮住远景，再到210米裁剪；阴雨和夜间按原天气密度提前雾化起点。天空本身不被这一深度雾覆盖。实现对应Godot的[深度雾](https://docs.godotengine.org/en/4.5/classes/class_environment.html#class-environment-property-fog-density)，不是直接提高指数雾密度压灰近景。

`LandscapeCoverage`在小镇和农园可拍照范围外继续铺地形，覆盖距离比镜头裁剪多32米。边缘地形按4米网格插值，树根使用同一插值；原有可走地面的形状与碰撞保留。远树使用现有夏树、银杏和杉树，按64米块合批，树种、位置、高度和朝向有固定种子的变化。自家花园和公共室内另补各自的树群与底地，只在对应室内显示，避免和其他场景串景；自由拍照临时启用远景雾，退出后恢复室内设置。

原来小镇的山/房屋背景画片、农园的平面树墙移除，避免高空或侧面视角露出画片的竖边。西侧公路和晴川水面延伸至视距之外，岸外地形和树木留出对应通道。实际游玩边界、钓鱼点、邻居路线和已有树干碰撞没有扩大。

## 资产处理

来源与原文件SHA-256见`art/manifests/models_reviewed_library.json`；项目维护者已于本次对话确认游戏商用和公开衍生源文件授权，第三方来源仍保留，不将其自动改为MIT。

提取入口：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --disable-autoexec \
  -P art/tools/import_reviewed_assets.py -- --source /path/to/asset
```

提取后走`art/tools/game_export.py`的保留分件导出路径，透明图片使用PNG，再跑`level_check.py`与Godot import。新GLB共7,787,776字节、17,785个基础三角面；原始源码在忽略的`art/models/raw/reviewed_library_20261012/`，游戏模型、导入配置和必要纹理进入Git LFS。

检查中修正了两类实际问题：

- CGC用灰度JPEG驱动透明度，直接复制Image会保留不透明像素格式。现在重新创建RGBA图像，白色/黑色遮罩进入Alpha，颜色独立重建；测试直接检查导入后的纹理Alpha。
- Blender选中状态可跨场景保留，后续文件曾混入先前已选物件。提取器强制只导出当前场景，17个导出逐项与原单体三角面预算比较；旧导出14项超预算，修后重新导出并检查。

## 验收入口

- `res://scenes/tests.tscn -- --only=landscape`：视距、雾、真实地形高度、树批次变换、透明度、单体隔离和实际摆放。原生执行还读取渲染器中的MultiMesh变换；headless的Dummy renderer读取不到变换时检查实际提交数组。
- `res://scenes/main.tscn -- --shots=<目录> --qa-landscape=1 --clean=1`：小镇/农园每处四个边缘点、八方向、低机位和24米高空85度广角，以及晴雨/早晚/夜间和新素材近景。
- `res://scenes/tools/landscape_probe.tscn -- --out=<JSON>`：1280×720原生窗口，两地各360帧旋转镜头，记录真实帧间隔、绘制调用和图元数。

本地证据集中在`evidence/asset_landscape_20261012/`。初次27项回归在修改前全部失败；后续补上Alpha、导出隔离和原生变换检查。最终1597项独占全量、40项原生专项、161张范围巡检与12张对比，以及解压包200项完整夏季演示通过。默认存档和照片摘要未变；已原子替换桌面包并删除冻结工程、解压应用和临时包，Web保持原版本。汇总见`delivery.json`。
