## Windows 草地白斑修复（2026-10-11）

Windows（RTX 3090，Vulkan Forward+）广场墙根与草坪边缘出现成片白斑。逐项排除确认来源是草叶：关掉草叶后消失，关距离淡出或花丛无效。实际生效的是材质选择B的`material_options/grass.gdshader`，它直接对`blade_height`和`sin()*.5+.5`做`pow()`。MSAA在像素中心着色细草叶，插值会越出顶点范围；`pow`的底数为负时，NVIDIA返回NaN，辉光再把NaN扩散成白斑。macOS未出现。现在两种草叶着色器都先clamp高度、随机值和风波，再计算`pow`。辉光不再按平台关闭，上一轮在另一份checkout里临时关闭Windows辉光的改动没有入库。`--only=plaza-quality`新增1项，旧着色器失败、修后9/9通过；6个原生视角的近白像素从最多约1万降到0，草地A单独复核也为0。Windows全量1539项中7项失败，都是PROPS/DISPLAY模型清单新鲜度检查，未改动的基线也是同样7项。证据见`evidence/windows_grass_glow_20261011/verification.json`。
