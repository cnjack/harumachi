# 玩法设计

## 玩家体验与动力

玩家是刚搬到晴町的新住户。通过认识邻居、完成小事、布置共享空间，让一个起初安静的庭院成为大家愿意停留的地方。

核心乐趣有三种：走进街巷发现生活细节；根据喜好选择帮谁、用什么装饰；在人物对话和空间变化中看到行动结果。首版不以体力消耗、惩罚性倒计时或反复刷材料维持时长。

核心循环：探索 → 交流与发现需求 → 选择委托 → 获取或使用物品 → 交付/布置 → 邻居回应与新内容 → 再次探索。

## 20–30 分钟试玩脚本

| 时间参考 | 玩家行为 | 可感知反馈 |
| --- | --- | --- |
| 0–3 分钟 | 公交入口抵达，学习移动与交互，进入自己的房间 | 获得钥匙和欢迎便笺；可自主环顾 |
| 3–7 分钟 | 在公告栏认识活动联络人，看见三项准备事项 | 任务明确，但顺序可选择 |
| 7–17 分钟 | 帮面包店送篮子、帮园丁准备种植箱、取回活动标牌 | 新对话、背包变化、材料奖励 |
| 17–23 分钟 | 在庭院布置摊位与座位，选择六种装饰中的两种 | 幽灵预览、合法位置提示、外观实时改变 |
| 23–30 分钟 | 检查清单并开始集市，与三位邻居交谈 | 人物到场，对所做选择给出不同回应，展示完成结果 |

时间是节奏目标，不是强制倒计时。玩家可以慢慢逛；只有主动选择“开始集市”才推进最终阶段。

## 五项委托与依赖

Q01「新邻居」：与联络人澪交谈 → 读取公告栏。解锁 Q02、Q03、Q04。

Q02「面包香的方向」：去 S02 面包店领取唯一任务篮 → 送到 P09 摊位位置。奖励一枚固定的邻里支持标记与一个装饰。篮子不能出售或丢弃。

Q03「庭院的新芽」：与园丁春交谈 → 在 H12 种植箱放入种子 → 使用浇水动作。植物土壤可以有局部浇水反馈，但街道始终干燥；没有全场下雨。首版作物通过后续任务步骤推进至成熟，回访即可观察变化，没有实时等待门槛。

Q04「把消息告诉大家」：取得活动标牌 → 在指定公告栏挂出。消耗标牌并设置社区活动已通知标记。

Q05「今天在这里见」：Q02–Q04 完成 → 在公共庭院放置摊位与座位 → 邀请三位邻居 → 玩家主动开始。可选装饰改变评语与画面，不决定是否成功。

独立分支顺序自由。已完成步骤不能回退到需要已消耗物品的状态。任务状态为锁定、可接受、进行中、可交付、完成；读档不能再次领取奖励。

## 选择与回报

准备经费首版固定 100 枚生活币，活动必要物资免费领取。装饰可选：花盆 25、旗串 30、桌布 20；其中最多选两类，形成轻量取舍。所有数字为待试玩调整的草案。装饰可拆回背包，放置不重复扣费。关键剧情永远不被花光经费卡住。

三位 NPC 各有 0–3 级熟悉度，首版只验证完成特定小事后变化一次，不靠无限重复对话刷分。奖励优先是个人故事、装饰配方与活动参与，而不是单纯提高数字。

无多人经济、无抽卡、无付费设计。扩展期再评估商店经营与更长成长线。

## 操作与系统

WASD 移动；鼠标控制受限的第三人称高机位镜头；E 交互；Tab 背包；J 委托；Esc 暂停。布置模式用鼠标定位、Q/E 旋转、左键放置、右键取消。进入 UI 后屏蔽角色输入。

交互距离初值 2 米，目标需要无遮挡；同一时刻只提示一个最接近视线中心的目标。文字提示说明具体动作，如“查看公告”，不只写“互动”。

背包初值 12 格，同类普通物品堆叠；关键任务物品用独立区域，不占满普通背包。交付逻辑原子化检查物品、消费、奖励与任务状态。

布置采用区域内 0.5 米网格和 90 度旋转，红/绿轮廓加文字说明是否合法。可用走道和出入口设置禁止区。只开放庭院与家门口，首版不支持任意建筑拆改。

NPC 只有两个剧情时段：准备阶段与集市阶段。对话期间暂停移动；切换阶段选择明确的导航目标，寻路失败时使用可见、安全的备用位置，不在玩家面前瞬移。
