## 图片生成顺序

1. 庭院在玩家镜头中的概念关键帧：展示可走范围、公告栏、菜圃和摊位空地。
2. 主角与三位居民形象表：统一比例、正侧背面、配色与服装；建模参考用中性站姿和柔和光照。
3. 三个 Hyper3D 样件的单体参考：每张仅一个主体，去掉编号、植物遮挡和强烈投影。
4. 玩家房间布局：床、书桌、简易收纳、出入口；不先制作多房间。
5. UI 草图与图标：先验证信息层级，再输出独立图标和装饰素材。

图片统一放 art/references 的版本目录，保存提示词和源图。需透明底的最终素材明确要求真实 alpha。图像生成的文字只作视觉草稿，正式 UI 文本由 Godot 渲染。

## UI 结构与交互

| 界面 | 必须显示 | 主要动作 |
| --- | --- | --- |
| HUD | 当前区域、剧情阶段、当前追踪目标、近处交互提示 | 打开背包/委托；不把任务列表铺满屏幕 |
| 对话 | 名字、简洁头像、可换行正文、明确选项 | 下一句、选择、结束；锁住角色移动 |
| 委托页 | 当前要求、已满足条件、交付位置、奖励 | 追踪与取消追踪，不允许丢掉主线 |
| 背包 | 图标、数量、类别、用途与任务物品区 | 查看、选择可放置物 |
| 布置模式 | 当前物品、旋转/放置/取消说明、合法性原因 | 地面预览、旋转、确定、撤销 |
| 菜单/存档 | 继续、存档、读档、设置、退出 | 覆盖存档要清楚说明，自动保存有反馈 |
| 集市结尾 | 做过的准备、邻居回应、布置结果 | 保存并继续探索或回到标题 |

HUD：左上短目标，右上区域与阶段，下方中央临近交互提示，右下仅在需要时出现按键说明。顶部保留天空视野；重要面板避开角色和脚下落点。

视觉使用米白纸感、墨蓝文字、青草绿与少量珊瑚色强调；图标是清楚的 2D 形状。正式按钮、面板和布局用 Godot Control/Theme 实现，生成图仅用于头像、物品图标和有限装饰。这样文字可本地化、按钮可缩放、交互状态可正确变化。

初始参考画布 1920×1080，支持缩放与锚点；正文参考 22–24 px，提供字号调整。禁止只用颜色表示合法/非法；同时有图标和文字。测试长中文、窗口缩放、焦点返回和暂停时输入隔离。
