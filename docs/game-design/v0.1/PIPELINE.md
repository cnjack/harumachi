# Hyper3D → Blender → Godot 制作流程

## 当前接入与来源

本轮工具清单和插件目录没有发现 Hyper3D/Rodin 集成，尚未验证账号凭据与额度。可采用官方 API 接入；新生成工作保持使用用户指定的 Hyper3D。现有 manifest 标为 hy-3d-3.1 的素材按既有来源保留，不能更名成 Hyper3D 结果。

既有 25 个 GLB 的存储网格合计 4,066,042 三角面，约 992 MB；单个长椅约 80,000 面，灯笼约 79,994 面。数据仅从 GLB JSON 统计，未计场景实例数、视锥裁剪或 LOD，也未进行真实帧率验证。详见 asset-audit.json。

## 图像与生成

每项资产记录稳定 ID、用途、目标尺寸、参考图、正面方向、可动部件、来源、生成任务 ID 和结果路径。生产参考采用干净单体图、平缓光照、无文字编号与场景背景；强烈树影可在后续打光中完成，减少固定阴影烘进贴图。

先做三个样件：P02 公告栏（有孔隙与细杆）、P09 摊位（大开口与独立道具）、S02 面包店（建筑体量与门窗）。样件通过后按每批 3–5 个、显式任务清单推进。门、柜门、招牌与售卖物需要独立对象；生成后检查是否糊成一体。

官方 Rodin Gen-2.5 支持图像生成和 GLB 输出；须显式指定 tier，避免落到默认旧代模型。导出 GLB、目标面数与材质模式均按样件验证结果设置，不用默认高面数批量提交。资料：[Hyper3D 官方文档](https://docs.hyper3d.ai/en/api-specification/rodin-gen2-5)。

提交后保存任务状态，处理限流、失败和重试；发生超时先查询已有任务，避免重复扣费。下载后校验文件、预览和来源记录。未得到有效文件不能标记完成。具体账户成本与批次数量在接入时核实，本轮未消费生成额度。

## Blender 整理规范

1. 使用独立副本导入，保留原始模型。单位以米为准，角色参考高度约 1.7 米。
2. 检查背面、底部、孔洞、悬浮碎片、法线与纹理；从至少前后左右四个角度验证。
3. 降面和重新整理 UV；保留轮廓与重要开口，植物细节优先通过贴图表达。
4. 模型原点落在地面中心或交互所需铰链位置；应用变换，固定朝向与命名。
5. 整理门、招牌等活动部件；避免把整栋可进入建筑做成封死的单块碰撞。
6. 制作独立的简单碰撞形状。远景和小装饰按需无碰撞；不要逐三角形覆盖所有细节。
7. 静态道具检查 LOD；纹理按实际屏幕占比选择尺寸，不给每个小物都用高分辨率图。
8. 输出 .blend 源文件、.glb 交换文件和预览，同时记录面数、尺寸、材质数、贴图大小。

下列仅是样件预算，未经实测：小道具 500–3,000 三角面；中等交互道具 3,000–10,000；可近看建筑 10,000–30,000；主角/重要 NPC 10,000–25,000。多数小物 512–1K 贴图，建筑 1K–2K，重要特写按需增加。规则道路与室内地板可由 Blender 精确建模，保证接口一致；有辨识度的建筑与主要道具由 Hyper3D 生成后整理。

## Godot 集成

Godot 支持 glTF/GLB 场景导入；本项目以显式 GLB 导出作为交接文件，Blender 源文件留在美术目录。资料：[Godot 官方格式文档](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/available_formats.html)。

Godot 中为导入模型包一层自有场景，挂交互、碰撞和导航，避免重导入覆盖玩法。角色用 CharacterBody3D；物件定义与委托定义做数据资源；任务状态、背包、时间阶段和存档由少量清楚的系统维护。先实现单机本地逻辑。

Blender 的复杂节点材质不假定能原样进入 Godot；把基础色、法线等烘成可控贴图，在 Godot 重建统一风格材质和灯光。先确定一个渲染器并实机验证；本机 Godot 4.8.dev6 是开发版，稳定版本与导出模板需要在工程开始时锁定。

动态人物需独立的拓扑、骨骼与动画工作：idle、walk、talk、简单操作、坐下至少五类。生成静态网格不等于已有绑定。先检查肩肘膝变形与脚底接触，再接入控制器。

## 导入和性能验收

样件必须能从四面看、站在旁边比较比例、走近不穿模、交互位置准确、重导入不丢行为。灰盒与最终模型共用交互点，便于替换。

性能目标：首版在指定测试机器、1080p、固定预设下争取 60 FPS；记录帧时间、显存/内存、可见面数和绘制调用，并标明场景与时长。先测量，再决定 LOD、合批、实例化、阴影距离和远景简化。不可用文件成功导入替代性能结论。
