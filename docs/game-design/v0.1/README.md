## 第一版体验

20–30 分钟的“周末集市准备日”：搬入社区 → 认识三位邻居 → 自选委托顺序 → 获得材料和支持 → 布置公共小角落 → 举办小集市 → 保存结果。玩家用行动改变公共空间，并获得人物回应。

第一版包含一小片可步行街区、三位 NPC、五个有限状态委托、一个室内、一个微型种植示范、有限布置和存档。联网、开放世界、完整经营经济、四季天气、自由建筑编辑器均留到后续。
