# 人物动作修订

用户反馈：第一轮主要是画面放大，人物没有有意义的动作。旧提示词过度强调保持站位、微小呼吸和禁止行走。已停止旧批量提交，首先验证同一张夏祭图能否产生明确动作。

## 第一段试片

输入：`art/references/promo_20261015/festival.png`。
完整提示词：`festival-action-v2-video.json`。

8秒单镜头、固定机位。空走向同伴，四次交替迈步，脚抬起并落地，手臂随步摆动；同伴抬手招呼；空停下并抬手回应。背景建筑和构图不靠缩放变化，人物的位置与姿态变化必须明显。保留原有画风、身份、衣服与夏祭场地。

验收时分别看全幅和人物局部的逐秒帧：有步态、有实际位移、有手臂动作，脚不滑行，人物不变脸，肢体没有明显变形。容器可解码只说明文件完整，不说明动作通过。

## 后续镜头设计（尚未提交）

| 场景 | 主要动作 | 场景内的意义 |
| --- | --- | --- |
| 小镇 | 空沿路走来，停在旧告示栏前，转头读它 | 回乡，发现停办的夏祭 |
| 早餐 | 空在座位上伸展双臂，再转头望向窗外 | 开始在晴町生活 |
| 烘焙店 | 莲离开柜台站位，转身走向面包架并抬手介绍 | 被邻居接纳，介绍店铺 |
| 农园 | 空蹲下查看幼苗，拨开一片叶子后站起 | 照顾亲手种下的作物 |
| 湖边 | 空向前挥竿，线落入水中，浮标荡开水纹 | 钓鱼玩法与日常休息 |
| 工作间 | 空扶稳灯笼骨架，把纸展开在桌面 | 为复办夏祭做准备 |
| 夏祭 | 空走向同伴，两人招手回应 | 前面的劳动带来真实相聚 |

每段先让一个动作完整发生，再考虑镜头运动；需要手指操作的镜头单独检查。动作必须从关键帧的实际姿态开始，通路或画幅不支持时先用imagegen调整首帧，不让人物穿过柜台或在画外完成动作。景物远景只作短暂建立场景，不用一连串缓慢放大替代人物表演。复杂动作无法稳定时换机位或简化为清楚的单一动作，不把失败结果包装成成片。
