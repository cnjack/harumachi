# 澪：保留原画的表情分层与关键形制作规范

本轮依据用户认可的原始眼睛、脸型、0.736 头部比例和衣袖拼接制作。它是现有可编辑素材的制作契约；本轮没有重新生成整张人物图。

## 参考与采用范围

- [AstraLayering](https://github.com/wu-tian807/AstraLayering/tree/8ab3486c2a46233ab6431690c53fc0d1dd9f6a70)：参考语义部件规划、隐藏区完整性、独显与叠合检查的组织方式。
- [Soullink Emotion SDK](https://github.com/nanlingyin/soullink-emotion-sdk/tree/02cd75ac0a085a87d84d1a885f1b33eca8742d53)：参考语义意图与表演通道分开、说话口型拥有独立控制权的设计。

实现与以下文字为本项目独立编写。没有安装两个项目的技能或运行其脚本，也没有接入 embedding 分类器。

## 素材约束

输入为 `native/mio-companion/Sources/MioApp/Resources/Mio/` 内现有透明 PNG 和 `Mio.rig.json`。所有坐标以现有 750×1000 画布及原注册位置为准；左右手按角色本人的左右命名。

1. 默认叠合必须仍是原来的澪。脸轮廓、眼距、虹膜比例、嘴部位置、头发轮廓和身体尺寸不借拆层重新设计。
2. 一个可见像素明确归属一个部件；仅在指根、发根等连接处保留受控重叠。眼白不得留下虹膜、睫毛或眉毛；掌心不得留下远端指尖轮廓。
3. 眼白延伸到虹膜后面；口腔底覆盖牙齿和舌头后面。延伸范围限于原图中已被遮挡的区域，默认合成不得增加可见杂色。
4. 输出保留原 alpha。不能按衣服或皮肤颜色删除背景。孤立轮廓应重新归属正确部件，不能仅从最终画面擦除。
5. 每一层先独显，再隐藏前景看下层，最后默认叠合。检查实际缩放后的画面，不只查看高分辨率原图。

## 本轮语义部件

| 部位 | 部件 | 动作职责 |
| --- | --- | --- |
| 每只眼睛 | 眉毛、眼白、虹膜、上眼睑、下眼睑、闭眼线 | 眉毛高度/角度；眼睑开合/笑眼；虹膜独立视线并裁切到对应眼白 |
| 闭口 | 上唇线、下唇线 | 原微笑、收敛嘴角、轻微皱口 |
| 开口 | 口腔底、舌头、上牙、上唇、下唇 | 开合、嘴角形态、收圆；说话停顿闭口 |
| 每侧掌心朝外的手 | 掌心与五根完整手指 | 指根固定，小幅错相张合；不把指节拆成零碎贴片 |
| 其他手形 | 放松、手背、侧掌、握拳、右手抵下巴 | 继续使用已注册的专用原画，切换时保持同一腕点 |
| 前发 | 前额/刘海、左侧发梢、右侧发梢 | 保留原轮廓，发根固定；两侧下部独立延迟跟随，避免整片头发同步摆动 |

瞳孔与高光随虹膜整体移动；没有新增瞳孔缩放或独立高光漂移。手指已有独立 ArtMesh，本轮使用一个每侧张合参数协调五指，不宣称完整手指追踪或任意三维翻掌。

## 表演要求

- 平静：眉眼放松，嘴角自然；温柔：轻微笑眼和微笑。
- 喜悦：眉毛舒展，下眼睑上抬，嘴角上扬；困倦：上眼睑下降，虹膜不压扁。
- 好奇：轻微不对称眉位与专注目光；关心：内眉抬起、嘴角收敛。
- 惊讶：眉毛抬起、眼睛稍张开、圆口；坚定：内眉略收、自信嘴角，可配肩旁小幅握拳。
- 表情轻/中/强由同一参数组控制。切换连续过渡；眨眼不能被表情重新撑开，说话的闭口停顿不能被表情覆盖。
- 普通闭眼使用较平的眼睑弧线，笑眼保留原上弯弧线，不能让关心、困倦和喜悦都变成同一种笑脸。
- 前发切口在原坐标 y=196–198 的两像素重叠带；独立摆动权重到 y=216 后才开始增长。验证同姿势拆层前后 alpha 和线条，不能把原有透明发丝误判成新裂缝。
- 深折肘的反向动作先释放原姿态；肩、肘、腕连接与手形一起检查。伸懒腰继续移除。

## 验证出口

源 PSD/CMO3 与标准 MOC3 同步。检查八种表情×三档强度、全部动作、25 组中途切换、长时钟和视线极值。用真实 Core 顶点和渲染像素检查接合，再人工放大审查轮廓；连接中心不透明不能单独代表自然。最终文件、证据和限制见 `docs/game-design/MIO_EMOTION_20261022.md`。
