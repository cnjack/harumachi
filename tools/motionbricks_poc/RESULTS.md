# MotionBricks 人物动画 POC：2026-10-18

已实际运行 NVIDIA MotionBricks，生成十条 G1 源动作，并映射到空、莲、春、澪、小葵、田中、和子七份人物模型副本。生成、重定向、原生播放和录像链路可用；目前的动作质量不适合直接接入游戏。

本次是独立实验。`game/` 和 `builds/` 共 5,105 个文件的前后 SHA/大小完全相同，104 个默认存档相关文件未变。没有创建虚拟显示器，没有使用游戏的动作、衣物或接触修饰器，也没有更新发布包。

## 看视频

以下路径均在仓库的本地、忽略目录中：

- `evidence/motionbricks_poc_20261018/review-v1/index.html`：七条单人、两条多人并排、源 G1 骨架，共十条视频；支持按动作跳播、慢放、逐帧、本地点评及 JSON 导出。
- `evidence/motionbricks_poc_20261018/overview.mp4`：三人组与四人组顺序拼接，160 秒。
- `evidence/motionbricks_poc_20261018/recordings-v1/`：各条原视频及验证记录。
- `evidence/motionbricks_poc_20261018/quality-findings-final.md`：七人 × 十动作的逐项问题与源骨架对照。

每条原视频 80 秒、1920×1080、30fps、H.264/BT.709，静音。每个动作展示 8 秒，依次切正面、右侧、斜侧；三个视角是连续时间的不同片段，不是同一相位的三机位。两组多人是同源动作的并排对照，没有模拟人物间碰撞或交互。

点评页已完成静态检查，但未完成浏览器实点验收：本轮内置浏览器工具的安全策略拒绝 `file://`。没有通过本地服务器或其它浏览器绕过限制。用户可自行打开本地页面；此限制不影响上述已验证的原生视频。

## 试了哪些动作

| 动作 | 这次可见的结果 |
| --- | --- |
| 站立 `idle` | 可播放；田中左前臂/手仍有衣身遮挡。 |
| 行走 `walk` | 能辨认走路；澪裙摆、和子围裙在抬腿时有穿插。不能据静帧宣布连续步态自然。 |
| 慢走 `slow_walk` | 与普通行走不同，脚部贴地移动仍须继续处理。 |
| 向左移步 `walk_left` | 明显屈膝、宽站，部分人物外八和下蹲过强；源 G1 也包含低姿态。 |
| 轻步潜行 `stealth_walk` | 有前倾、屈膝与手臂前置；长衣片未能可靠让开腿。 |
| 低身潜行 `walk_stealth` | 能生成低姿态，但莲出现明显腿部尖折、围裙穿插；澪和和子也有衣物问题。 |
| 负伤步态 `injured_walk` | 可辨认不对称动作；田中的落脚修正较大，不能视为已解决支撑。 |
| 欢快舞步 `walk_happy_dance` | 有抬臂和舞步变化；仍沿用人物中性手指，衣物问题未消除。 |
| 拳击步态 `walk_boxing` | 有防守抬臂姿态，但手没有形成完整握拳。 |
| 手足爬行 `hand_crawling` | 手端悬空、偏膝腿支撑；长衣片穿插突出。源 G1 本身也有低躯干、屈膝姿态，不能将全部问题归于重定向。 |

逐项审查实际查看了 210 张人物参考帧和 30 张源骨架参考帧，并对重点问题复看原尺寸图。截图不替代连续节奏、完整表面碰撞或接触力验证。几何审计也发现厘米级落脚修正与近地材质点移动；后者不是物理接触真值，不能直接等同精确脚滑距离。

## 来源与验证

使用[固定 NVIDIA 官方源码](https://github.com/NVlabs/GR00T-WholeBodyControl/tree/45c03facbf848e0c743091b7d9c17952096ff908/motionbricks)与原权重，在本机 CPU 上推理。此公开模型面向 G1；这是 G1 → 人物重定向，不是官方人体模型原生生成七种人物身份。公开菜单没有 `run/sprint`，本轮没有把走路加速后冒充跑步。十个片段独立开始，不声称片段间连续生成过渡。

- 真实源数据：10 × 240 帧；root、pose、VQ decoder 每部分各执行 160 次。全部权重核对官方 Git LFS SHA 与大小。
- 独立 MuJoCo FK 对照源动作：位置最大误差约 0.329 微米。
- 七人 GLB：70 段、16,800 帧；原网格、材质、蒙皮、原动画及骨长保持，后处理的 IK/接触修正另行记录。
- 原生实际播放：285,600 个骨世界变换样本，最大位置差 2.20 微米，源帧逐项覆盖，无漏首帧或额外尾帧。
- 录像：十条共 24,000 帧，全部严格解码通过；同帧 PNG 与 AVI 邻帧比较确认裁剪位置，原始 AVI/WAV 在成功后清理。
- `python3 tools/check_project.py`：7,775 项通过；四项源导出格式/拒绝错误数据测试通过。

原生录像关闭导入动作曲线优化，并在本轮临时工程中清缓存重新导入；这解决了初轮录制的导入简化误差。正式视频与本次生成姿态对应，未用游戏原走跑动作替换。详细收据在 `media-summary.json`、`native-playback-audits-solo-summary-v1.json`、`production-isolation.json` 和 `recordings-v1/integrity-and-cleanup.json`。

如果继续这条路线，应先处理手/脚接触约束、目标人物比例和长衣片变形，再考虑动作风格与年龄差异。现阶段的价值是验证生成与重定向路线，并把不适配之处具体呈现出来。安装和复现命令见 [README.md](README.md)。
